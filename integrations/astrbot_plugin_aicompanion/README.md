# astrbot_plugin_aicompanion：让 QQ 上的她和桌面上是同一个她

QQ 接入不自己写：**NapCat** 把 QQ 接成 OneBot，**AstrBot** 负责平台、群管理和指令，这个插件只做一件事——
把选定的 QQ 会话转给本机 AICompanion 桌宠，由桌宠的大脑（同一个人格、同一份记忆）回复。

```
QQ ⇄ NapCat ⇄ AstrBot ─(本插件，POST 127.0.0.1)→ AICompanion 桌宠 → DeepSeek
```

## 谁能和她说话（由桌宠判断）

| 会话 | 怎么处理 |
| --- | --- |
| 你（桌宠里绑定的 QQ 号，她管你叫爹）的私聊 | 和桌面同一段相处：共用聊天记录、记忆、心情 |
| 允许的群（插件和桌宠两边都要填） | 群里每条消息她都旁听（记进这个群的聊天记录，之后整理成记忆）；被 @、叫唤醒词或提到她名字时回复；没人叫她时按桌宠里的"群里活跃度"偶尔插话，没什么好说就不说 |
| 陌生人私聊 | 默认不回；桌宠设置里打开后回复 |

**记忆是共享的**：群里听来的事（写清楚是谁说的）会整理进同一份记忆，她在桌面上也记得；桌面上记住的事在群里也能用。
不想在群里被提到的记忆，到桌宠"设置 → 记忆"里选中后点"设为只在私下用"。和你的对话摘要只在私下用。
| 其他群 | 插件不管，交还给 AstrBot |

从插件 0.12.0 起，绑定的主人可以在 QQ 私聊说出任务，或以文件形式发送附件。任务在桌面程序里执行。她先发“要我动手吗”，需要审批时给出短编号。回复“同意 编号”或“拒绝 编号 原因”，也可以直接在桌面处理。显示了可复用规则时可回“同意这类 编号”“以后都允许 编号”，或用“同意全部”确认同一任务已收到的可批量操作。当前请求 120 秒后失效。开始、完成或失败会在主人私聊收到通知。

群聊和其他私聊没有办事权限。旧版插件仍能聊天。桌面程序关闭时，由仍在线的插件回复离线提示。

插件配置里的"群里只转发 @ 她或叫唤醒词的消息"默认关掉；一键接入会把旧版存下的"开"改成关。想要旧行为，在桌宠里把群里活跃度选成"只在被叫时说话"。

## 一键接入（推荐，Windows x64）

不用自己装任何东西：桌宠"设置 → 聊天平台"点 **接入 QQ**。
1. 确认下载提示后，桌宠从 NapCat、uv、PyPI 的官方地址下载固定版本的组件，校验后装进 `%LOCALAPPDATA%\AICompanion\qq\`，
   并自动写好 NapCat ↔ AstrBot、插件 ↔ 桌宠两段连接（各自的随机令牌，只监听本机），然后启动它们。
2. 页面出现二维码后，用手机 QQ 扫码登录**机器人账号**（建议用小号）。验证码、设备验证需要你自己完成，桌宠不会绕过。
3. 显示"已连接"后，填你自己的 QQ 号（她管你叫爹），在列表里勾选允许她说话的群，保存。

页面上有 启动 / 停止 / 重试 / 复制诊断信息；端口、令牌、组件目录、Python 包镜像在"高级设置"里。
已经有 AstrBot 的，在高级设置里点"改为接入已有的 AstrBot…"，选它的根目录：桌宠只安装 / 更新这个插件和它自己的配置文件，
不改你的 cmd_config.json、其他插件、NapCat 和账号数据；NapCat 和 AstrBot 之间的连接沿用你原来的。

## 手动安装步骤（Windows，同一台电脑）

1. **桌宠**：设置 → 聊天平台，勾选"打开本机接口"，填你的 QQ 号和允许的群号，保存；点"复制令牌"。
2. **AstrBot**：按官方文档安装并打开管理面板（默认 http://localhost:6185）：https://docs.astrbot.app/deploy/astrbot/desktop.html（桌面版）或 https://docs.astrbot.app/deploy/astrbot/windows.html
3. **NapCat**：把 QQ 接成 OneBot v11，用反向 WebSocket 连到 AstrBot：
   AstrBot 的 OneBot v11 接入页 https://docs.astrbot.app/platform/aiocqhttp.html ，NapCat 官方的接入说明 https://napneko.github.io/use/integration 。
   建议用一个小号当机器人，不要用主号。
   注意：NapCat 和 AstrBot 之间的 token（反向 WebSocket 的令牌）和桌宠的令牌是**两回事**，不要填混。
4. **装插件**：把本文件夹整个复制到 AstrBot 的 `data/plugins/astrbot_plugin_aicompanion/`，在管理面板"插件"里重载；
   插件配置里填：桌宠接口地址（默认 `http://127.0.0.1:18765`）、令牌、交给桌宠的群号。
5. 用主号私聊机器人说一句话，桌宠应该以她的口吻回复；在桌宠的聊天面板里也能看到这段对话。

## 说明

- 第一版要求 AstrBot 和桌宠在**同一台 Windows 电脑**上运行：插件访问的是 `127.0.0.1`。AstrBot 如果跑在 Docker / 虚拟机里，
  容器里的 127.0.0.1 指的是容器自己，连不到桌宠。
- 聊天记录：同一个群的人共用一段记录（每条前面是"昵称#编号"，同一个人编号不变，数据库里另存完整的稳定 ID）；不同群、陌生人私聊、桌面的
  聊天记录互相不直接可见，彼此之间通过共享的记忆知道对方那边的事。
- 首次验收请用合成的测试记忆（例如一条"主人喜欢蓝色杯子"标成"只在私下用"、一条"主人喜欢看海"保持共享）检查，不要拿真实私事当探针。

- 插件和桌宠只通过本机 HTTP 接口通信，不复制 AstrBot 代码；插件按 AstrBot 插件接口（AGPL-3.0）编写，随 AstrBot 使用时遵循其许可。
- 依赖：`aiohttp`（AstrBot 自带）。
# QQ 图片和表情包（v0.4）

桌宠和插件一起更新后，支持纯图片、图文，以及文字配表情 / 只发表情。图片由 AstrBot 原有组件解析，插件压缩到最长边 1600 像素后转给桌宠；每次最多 3 张，每张最多 1 MiB。动图识别首帧，发送本地 GIF 表情仍保留动图。

在桌宠“设置 → 聊天平台”中打开“看懂收到的图片”和“聊天时可以发表情包”，保存即可；识图开关通过心跳同步给插件（最多 15 秒）。只有被允许的 QQ 私聊 / 群能识图，群旁听不自动上传图片。图片必须是 AstrBot 已解析到其受管理临时目录中的媒体，不转发任意文件路径。

识图复用同一官方 DeepSeek 接口的凭据，默认 `deepseek-flash`，不会强制切换原聊天模型；视觉描述交给原桌宠大脑，原图和 base64 不进入聊天历史。识图会增加一次模型请求，用量归入当前聊天用途；等待包含图片的回复时在原超时基础上额外留 45 秒。

表情默认使用仓库原创鲸娘姿态，也可在桌宠里选社区基础包 `manifest.json` + `memes/<category>/<image>`，或普通 `<category>/<image>` 目录。模型只选择分类，一次最多一张，同一会话默认间隔 60 秒；图库中的路径或网络地址不能成为模型指令。无需再安装图床、向量库或另一个聊天插件。

### v0.5：自然表达与头像

表情也是日常表达方式：她可主动选图或只发表情，不要求用户先说“发表情”。群里没有值得接的话也可保持安静。聊天习惯保存在桌宠，按角色 / 人 / 会话隔离，可在“聊天习惯与社区”查看、关闭和清除；不改写人设或训练模型权重。

头像在 `/v1/media-permission` 核验允许场景、费用、触发方式和缓存后，才从固定 QQ HTTPS 头像服务获取；仅数字 QQ 号、无重定向、最多 128 KiB。默认当前对话者，问头像并 @ 群友时可看该群友。一天内复用视觉描述，不保存头像原图，不凭头像推断真实身份；失败不影响正常回复。

公开社区话题由桌宠单独后台刷新，不上传聊天、不登录网站。原生发送仍使用 AstrBot 图片链，媒体等待超时会按是否含附件 / 头像为额外视觉调用留出时间。

## 多段回复（v0.7.0）

她想连发几句时，桌宠会把回复拆好放在 `segments` 里，插件按顺序一条一条发，每条之间停一小会儿，像真人打字。表情包单独发一条（图在前就先发图，图在后就最后发图）。某一条发送失败时就停下，不重发、不打乱顺序。像代码、列表、长讲解这类内容不会拆开。

## 0.10.0：主动消息先领取再发送

桌宠主动发到 QQ 私聊的消息，插件先向桌宠领取（`POST /v1/outbox/claim`），领到才发送。发完回报结果（`POST /v1/outbox/ack`）：全部发出 / 部分发出 / 失败，第一段实际发出后过了几秒，发出了几段。回执没送到会重试几次。
桌宠只按这些回报判断“发没发到、什么时候发到、纪念日算不算提过”。0.9.x 的插件不会先领取，桌宠不再用它主动发消息，聊天和群回复照常。升级桌宠后请同时更新插件。


## 0.10.1：结果不确定时不重发

- 发送超时、连接断开时，消息可能已经送到，只是没等到平台的响应。这类情况回报 `unknown`（不确定），桌宠不会再发同一句。只有平台明确拒收才回报 `failed`。
- 分段发送中途插件被停用：已经发出的几段按 `partial` 回报，不会报整条发出。
- 先发表情、后发文字时，首达时间按表情发出的时刻算。
- 回执多带一个 `first_after_claim`（领取后几秒第一条发出）。桌宠用自己记下的领取时刻换算首达时间，回执在路上耽搁多久都不影响。

## 0.10.2 主动消息与插件更新

主动消息要求运行中的桥接插件为 0.10.2 或更高版本。桌宠在每次心跳和领取时核对版本，旧插件仍可回复用户发起的私聊和群聊。

打开「设置 → 聊天平台」查看当前运行版本。自动安装模式下点击「更新插件并重启」。接入已有 AstrBot 时，点击「更新插件」，然后到 AstrBot 管理面板的「插件」里重载 `astrbot_plugin_aicompanion`，或重启 AstrBot。桌宠收到新版心跳后恢复主动消息。
