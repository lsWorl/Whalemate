# T24 视频生成提示词模板（Claude，2026-11-15）

第一批 6 段的教训：用 Seedance 1.0 Fast 且只给首帧时，即使提示词写得很细，模型也会把“鲸鱼女仆”画成一条鲸鱼，背景变色、出现阴影、转身。**每段都必须用 2.0 mini 首尾帧模式、按秒写动作、带上通用约束。**

## 生成设置

| 项 | 设置 |
| --- | --- |
| 平台与模型 | 即梦网页版 Seedance 2.0 mini（没有就用 2.0 fast）；**不用 Seedance 1.0 Fast，不用“仅首帧”** |
| 模式 | 首尾帧。正面动作首尾都用 `anchor/anchor-a-16x9.png`；走路首尾都用 `anchor/side-a.png` |
| 时长 / 比例 / 清晰度 | 5 秒，16:9，720P（最后缩到 512×288，720P 足够）；有“生成音频”开关的话关掉 |
| 每个动作 | 每次只生成 1 段（负责人 2026-11-15 要求），审片不过再重抽；同一动作 3 段都不过就换万相 wan2.2-kf2v-flash（见 T24 任务说明） |
| 记录 | 下载原片放进 `clips/<动作>-v<n>.mp4`，在 `prompts.json` 里记下模型、模式、积分、种子（如有）、**网页里实际粘贴的完整提示词** |

## 通用约束（每段提示词末尾原样附上）

> 画面固定机位，镜头完全不动，不推拉、不摇移。背景从头到尾都是均匀的纯绿色（#00FF00），颜色和亮度不变，没有地面、阴影、反光、文字或水印。人物始终是参考图里的同一个人类少女：脸、发型、发色、女仆装、头饰、耳边的鲸鳍和身后那条细小的鲸尾都保持原样，鲸尾大小不变；她不会变成鲸鱼或其他动物，画面里不出现其他角色或物体。人物始终完整地待在画面中央，大小和位置不变；镜头距离不变，人物大小始终与第一帧相同，不出现特写。最后一帧与第一帧的姿势完全相同。

万相 API 另加反向提示词（`negative_prompt`）：
`鲸鱼, 动物, 第二个角色, 地面, 阴影, 文字, 水印, 背景变色, 镜头移动, 转身, 走出画面, 人物变大变小, 多余的手脚, 脸部变形`

## 1. idle 待机

沿用 `idle-v1`（已通过），不重做。

## 2. talk 说话（正面锚点）

> Q版鲸鱼女仆少女站在原地开心地说话。0–1秒：嘴巴张开说话，下巴轻轻上下动，头向右轻点一下。1–2秒：继续说话，嘴型有大有小，眼睛开心地眯一下，右手在胸前轻轻抬起比划一下。2–3秒：右手放回身侧，继续说话，头向左轻点一下，呆毛跟着晃。3–4秒：继续说话，眨一次眼，长发和小鲸尾轻轻摆动。4–5秒：慢慢合上嘴，回到第一帧的站姿和平静表情。双脚始终不动。 + 通用约束

## 3. happy 开心挥手（正面锚点）

> Q版鲸鱼女仆少女开心地向前方挥手打招呼。0–0.5秒：预备，身体微微下沉，肩膀向下收，眼睛眯起准备笑。0.5–1.5秒：右手从身侧抬到头旁边，掌心朝前，开心地张嘴笑，身体随之轻轻上抬，长发和裙摆向上扬一点。1.5–3秒：右手左右挥动三次，头随节奏微微左右歪，呆毛和耳边的鳍跟着抖。3–4秒：手放下，身体轻轻回弹一下（略微下沉再回正），裙摆和头发比身体慢半拍落下。4–5秒：表情恢复平静，回到第一帧的站姿。双脚始终不离地。 + 通用约束

## 4. walk 原地走（侧身锚点 side-a）

> Q版鲸鱼女仆少女侧身朝向画面右侧，原地踏步走路，像走在跑步机上：身体不向任何方向移动，不转身，不回头看镜头。每秒走两步，左脚、右脚交替抬起再落回原处，抬脚很低，小短腿；每落一步身体轻轻向下颠一下；双臂与腿相反，前后小幅摆动。长发、裙摆和身后的小鲸尾比身体慢半拍地轻轻摆动。0–4秒持续踏步，共 8 步；4–5秒最后一步落地，双脚回到第一帧的位置站定。 + 通用约束

后期从 0–4 秒里截取整数个步伐周期做循环（不用 4–5 秒的收尾）。横向位移和左向镜像都由程序完成。

## 5. turn 转身过渡（首帧正面锚点、尾帧侧身锚点）

> Q版鲸鱼女仆少女从正面站姿轻轻转向画面右侧，变成侧身朝右的站姿。这是一次很小的四分之一圈转身：她只向自己的左手边（画面右侧）转 90 度，脸始终朝向观众或画面右侧，全程看得到她的脸和眼睛，绝不背对镜头，不转一整圈，不朝画面左侧转。她的小鲸尾始终在画面左侧、身体后方。双脚不离地、不走动。0–1 秒：保持正面站姿。1–2.5 秒：头先转向画面右侧，身体和双脚跟着小步原地转到侧身，长发和裙摆轻轻甩动。2.5–5 秒：保持侧身朝右的站姿不动，头发和裙摆慢慢静止，姿势与尾帧参考图完全相同。 + 通用约束（去掉最后一句“最后一帧与第一帧的姿势完全相同”，因为首尾帧本来就不同）

经验：只写“转身 90 度”时，模型可能经背面绕大半圈（turn-v1）。必须写明转向哪一侧、脸始终可见、不背对镜头。
