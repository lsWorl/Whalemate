# 项目原创鲸娘美术归档

鲸鲸使用本机安装的 Aboutme 大肥鱼动画，尚未安装时显示占位形象。安装步骤、来源和许可见 [Aboutme 素材说明](../docs/aboutme-pet.md)。

此前实际使用的原创鲸娘素材保存在 `archive/deepseek-whale/`。其中 `source/` 是分层源包，`sprites/` 是整张立绘，`rig/` 是已编译的骨骼和纹理。此归档供继续创作或查阅。

这些项目原创素材、[应用图标](../src/aicompanion/assets/icons/)及[六张原创表情图片](../src/aicompanion/assets/expression/)按根目录的 [MIT License](../LICENSE) 发布。图案中出现的公司名称和徽标仍是各自权利人的商标。

Aboutme 和 dsh-pet 的上游美术禁止商用，公开二创须署名 PC2005-cloud/dsh-pet。其原始图集和转换产物均不收录在本目录。
