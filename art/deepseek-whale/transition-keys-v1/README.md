# 原鲸娘站坐过渡关键帧

使用内置 image_gen，参考当前运行图集的待机、工作、抱鲸犯困首帧，各画四张下蹲 / 落座中间姿势，共八张。人物沿用原鲸娘的设计、服装、鲸尾与标志。两张 `*-sheet.png` 是原始工具输出，同名目录保存归一化后的单独关键帧；提示词见 `prompts.json`，同一缩放与脚底锚点记录见 `alignment.json`。

坐下时头部降低，不把坐姿重新放大成与站姿等高。工作只使用目标动作里的电脑，犯困只使用目标动作里的蓝鲸玩偶。

大幅姿态之间直接混合图像会出现双脸、手脚和蕾丝重影；最终使用单张原画的头部 / 脚底 / 行轮廓变形，在补画姿势之间逐格接续。运行过渡包含原始端点，首尾以无损 WebP 保存，与源 / 目标动作首帧的预乘颜色一致。它是短逐格过渡，不是物理运动捕捉；手指与道具交接仍需人工审图。

`tools/build_pose_transitions.py` 将主循环首帧、新画和轮廓补间编译成 22 段过渡，记录输入 / 输出 SHA256 于运行素材的 `TRANSITIONS.json`。改动主循环后应重建过渡；完整 `tools/build_original_animation.py` 会自动执行两步。

本机旧版双图 / 光流预览因重影留在 output/transitions 中，不作为运行资源。最终预览使用无版本后缀的 idle-to-working.gif 和 idle-to-sleepy.gif。
