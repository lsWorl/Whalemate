# 唯一参考图：十动作素材

角色身份仅来自 user-identity-reference.png（用户 2026-11-10 上传）。不把其他版本的人物作为本批造型依据。保留原图的脸型、蓝眼、深蓝长卷发及青蓝发梢、椭圆蓝色头顶装饰、蕾丝发箍、蝴蝶结、鳍形白饰、女仆裙 / 围裙 / 鞋子和鲸尾。原图已有鲸鱼图案保留；不另加水印。

内置 image_gen 为左右行走和八个互动各生成六张关键姿态，另生成一张统一标准站姿；左行走再针对三分之四朝向细化一次。所有完整提示词与编辑目标见 prompts.json 索引和 prompts/。walking_left-first.png 是细化输入，不参与运行。图纸可见的独立小符号 / 预览底色不进入提取后的主体。

导出：tools/build_reference_motion.py --png-frames。每个动作 384×384、12 FPS、120 帧、10 秒；透明背景。正常站姿头顶约18%、脚底约85%，身高约67%；不按每个动作包围框反复缩放身体。所有帧四边至少10%安全边距。

左右行走分别画，编排八个完整步态周期，偶尔眨眼。八个互动首末共用 standard-stand.png；三个小跳在2～6秒中完成。所有动画首末帧 RGBA 精确一致。图集使用无损 WebP exact=True，避免编码器改变透明像素的 RGB。

这不是视频模型生成或1200张手绘。离线编排使用已有 Pillow / NumPy、小段光流和单原画采样，避免交叉混合出两张脸 / 四只手。图纸和动作结构做过目视检查，但自动边距 / 首尾校验不能证明所有插值都符合人体结构；动作自然程度、五官 / 服装的细微一致性仍需用户审图。

运行素材：src/aicompanion/characters/deepseek-whale/animation-reference-v1。逐帧PNG、单项GIF、透明动态WebP和总览在 output/reference-motion-v1。旧 animation-original 的图集未覆盖；播放器合成对应新动作，右键“动画版本”可切回旧版。新模式使用本批左右步态，旧二维实验不会作为本批新动作使用。
