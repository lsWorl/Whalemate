# 原鲸娘新绘关键帧 v1

参考仅使用本项目已确认 `originals/idle.png`、`talking.png`、`thinking.png`，保留原角色设计、头身比例、长袖女仆装、鲸尾及标志；没有使用 Aboutme / dsh-pet 的图像或声音。

用 **内置 image_gen** 分别绘制待机、说话、托腮思考的 6 张关键帧，共 18 张。完整提示词保存在 `prompts.json`，每个 `*-sheet.png` 是对应工具原始输出，三个同名目录是经过主体提取和脚底对齐的 384×384 透明关键帧。`alignment.json` 记录各主体边框、脚底锚点和缩放。

第一版 8 格待机稿的格子留白不足，仅留在本机忽略目录，没有作为本包素材。最终提取按六个独立主体进行，因此图纸的少量格子偏移不会裁断鲸尾；清理与主体断开的微小残屑，保留半透明轮廓。保持同一缩放与脚底锚点，防止足底跳动。

运行图集使用双向金字塔光流进行离线补间，透明颜色采用预乘 alpha，生成 24 fps 循环。**18 张是新画的关键帧，不是模型生成了每一帧视频**；其余动作沿用本项目的原画并施加小幅连续形变。补间只适用于这些小幅动作，大幅肢体运动需要新增原画。

离线工具：`tools/build_original_animation.py`、`tools/animation_inbetween.py`；锁定的编译依赖见 `tools/original_animation_requirements.txt`，本机已安装，未新增桌宠运行依赖。

运行资源的 `SOURCE.json` 记录原参考、原始工具输出和每张图集的 SHA256。新画与动画观感仍需用户确认，不写成已批准的新设计。
