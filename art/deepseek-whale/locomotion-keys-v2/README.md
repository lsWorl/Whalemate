# 低步幅正反行走

用户要求步态轻巧、不要高抬腿。内置 image_gen 重画正面 / 背身两组六张关键帧，保留大肥鱼原特征。rear-identity-reference.png 是本项目自己绘制的背身身份参考，仅用于服装与发型，不作为步态。

运行循环上身取自六张新画的小幅补间，腿部离线提取为两层并做低幅运动，源图不覆盖：脚部横向幅度 10 px，单脚抬升不超过 5 px（384 px 原帧）；近直膝，双脚轮流承重。不是二十四张逐帧手绘，也不是模型训练。生成提示词见 prompts.json；计算方法见 tools/low_step_walk.py，运行来源和参数见 SOURCE.json。

桌面按实际移动距离推进循环，起停有加减速。向上 / 斜上使用背身，其他方向使用正面和镜像；两种画面覆盖八种路线方向，并非八套独立透视原画。参考尺寸 300 px 时一个步态周期对应约 32 px 位移；基础行走速度 42 px/s，跟用户缩放比例变化。拖拽、下落、聊天和忙碌状态优先。

尚需用户真机确认步态、支撑脚滑动感和镜像方向，不把离线检查当作审美验收。
