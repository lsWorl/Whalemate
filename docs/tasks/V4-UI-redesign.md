分工：**Codex 实现，Claude 审计**（负责人指定）。分支 `task/v4-ui-redesign`，从 `collaboration-baseline@1ee25db` 拉出。

设计稿（负责人已确认）：https://claude.ai/artifact/GDNm7yKyyEwhV1gnZs961B 。
仓库里的副本在 `docs/design/v4-ui/*.dc.html`，图片已改成指向仓库里的立绘。这些文件只用作参考，看颜色、尺寸和文案；它们依赖设计工具的运行时，不能直接在浏览器里完整显示。

## 负责人已确认的决定

1. **设置页名称不改**：沿用“概览、角色与形象、关系与心情、记忆与心事、主动与提醒、模型与 Key、声音与通话、办事、表情图库、QQ 与社区、存储位置、用量”，分组仍是“她 / 能力 / 连接 / 系统”。只换样式，每项加一个图标。
2. **设置改为自动保存**，并且要让用户知道：底部状态写“✓ 已自动保存 · HH:MM”，旁边一句“这里的改动会马上生效并自动保存，不需要再点保存”；“取消 / 保存”两个按钮换成一个“完成”。
3. **聊天面板去掉模型名**：模型只在“模型与 Key”里显示。
4. **Aboutme 素材**：向导和设置里只显示占位框和“安装后显示”，安装后才显示真实动画；上游贴图仍然不进仓库。

## 范围

### A. 鲸鲸主题（`ui/theme.py` 及各处样式）
- 配色：
  - 鲸鲸蓝 `#2F5BEA`：主按钮、选中、链接；悬停 `#1E3FB8`；
  - 深海 `#13234A`：正文；
  - 灰蓝 `#5A6787`：说明文字，在白底上对比度 ≥4.5:1；`#4B587A` 用于次要正文；
  - 泡泡蓝 `#E6EEFF`：她的气泡、选中底色；
  - 围裙白 `#FBF8F3`：窗口背景；
  - 卡片白 `#FFFFFF`，描边 `#E3E8F3`，输入框描边 `#D9E1F2`；
  - 浪花青 `#3FB7C9`：进度条、点缀，**不用作文字颜色**；
  - 状态色：成功 `#16683F` 配底 `#E3F6EC`；提醒 `#8A4A00` 配底 `#FFF1DC`；危险 `#A3361A`。
- 字体：保持 `Microsoft YaHei UI` 等现有字体栈。字号层级：标题 24 粗体、小标题 16 中粗、正文 14、说明 12～13。
- 形状：卡片圆角 16～20，主按钮高 44、胶囊形，图标按钮 36～40 的圆形，可点区域不小于 36px。
- 图标：统一用线性描边图标（设计稿里的 SVG 路径可以直接用），扩充 `ui/icons.py`；**不用 emoji**。
- 插图：空状态、等待、出错、完成，直接用角色包现成的立绘（sleepy / thinking / error / celebrate），不另外画。

### B. 聊天面板（`ui/main_window.py` 的顶栏、消息区、输入栏、`ui/chat_view.py`、`ui/agent_session.py`）
- 顶栏：头像、名字、状态行（绿点 + “在线 · 心情 xx”，没配模型时显示“还没连上模型”），右侧只放两个图标按钮：朗读开关（喇叭）和设置（齿轮）。去掉模型名、`StatusPill` 和角色下拉框。
- 切换角色：只有一个角色时隐藏入口；有多个角色时，点名字弹出菜单切换，桌宠菜单“她的样子”里也能切换。
- 她的气泡左侧带 28px 小头像，配色按 A；时间分隔用浅色小标签。
- 办事进度卡：标题“她正在帮你做事”、一句当前进展、进度条，需要审批时显示“同意 / 让她停下”两个按钮。现有审批逻辑不变，只改外观和文案。
- 输入区：
  - 上方是“聊天 / 帮我做事”分段切换，对应现有的 `agent_toggle`，行为不变；
  - 输入栏依次是：回形针（现有 `＋`，功能没做之前保持禁用并给提示）、输入框（占位“和鲸鲸说点什么…”）、麦克风（就是现有的“通话”）、发送；
  - 停止按钮只在她正在回复或干活时出现；
  - 选中“帮我做事”时，下方显示一行说明：“她会动手操作电脑，改文件前都会先问你。”
- 没配模型时的引导条保留，改成新样式，按钮文案“去连接模型”，打开向导第 2 步或“模型与 Key”页。

### C. 桌宠右键菜单（`ui/desktop_pet.py`）
- 顶部：头像、名字、状态（不可点）。
- **和她说话**：说点什么…（右侧标注“双击她”）、打开聊天窗口、语音聊天（开启后改成“结束语音聊天”）。
- **让她帮忙**：交给她一件事…（忙的时候改成“让她停下手里的活”）、专注一会儿 ›（原“专注模式”子菜单）。
- **她的样子**：做个动作 ›（有动画版时合并原“动画动作”，没有时用原“做个动作”）、大小 ›、换个角色 ›（只在角色多于 1 个时出现）。
- 分隔线，然后：设置…、让她休息（藏到右下角）、退出鲸伴（危险色）。
- “打断回复”只在她正在说话或生成时出现。
- 移到 **设置 → 角色与形象 → 更多** 的项：动画版本、走几步、配色、开机自动启动、其他“桌宠设置”子菜单项。功能和数据库键保持不变。
- `QMenu` 用 QSS 统一样式：圆角、图标、分组小标题（可以用禁用的 `QAction` 或 `QWidgetAction`）。

### D. 首次启动向导（新文件 `ui/onboarding.py`）
- 一个 5 页的 `QDialog`，左侧是插图栏（泡泡蓝底、立绘、进度点），右侧是内容，文案按设计稿：
  1. **欢迎**：三条能力介绍；“开始准备” / “先随便看看”（直接跳到第 5 页）。
  2. **连接模型**：选服务卡片（DeepSeek 推荐 / MiniMax / 其他兼容服务）；“还没有密钥？三步拿到”，带 DeepSeek 开放平台链接 `https://platform.deepseek.com/`；密钥输入框（密码样式）；“测试一下”按钮，在后台线程里跑，成功时显示她回的一句话，失败时给出能看懂的原因（密钥错误 / 余额不足 / 网络不通）；“先跳过（离线试用）”。**保存时复用 `model_page` 现有的账户和凭据接口（DPAPI），不要另写一套。**
  3. **声音**：电脑自带声音（默认）/ 鲸鲸专属声线（需要另一个服务的密钥，选中后展开填写，可以留到以后）/ 先不出声；“试听”复用现有的预览功能；智能朗读开关。
  4. **样子**：自带鲸鲸（已就绪）/ 大肥鱼动画版（占位框）；“安装”按钮在后台调用 `tools/install_aboutme_pet.py` 的安装逻辑，显示进度，可以取消；写明来源和非商用许可。打包版里不能安装时，给出 `docs/aboutme-pet.md` 里的步骤。
  5. **完成**：三招小抄（双击 / 右键 / 拖动）；“在 QQ 上聊天”“让她帮你做事”两个可选入口，跳到对应设置页；“开机时让她自动出现”勾选框；“开始陪伴”。
- 什么时候出现：
  - 新安装：没有 `onboarding_done` 标记，并且没有配置过模型；
  - 老用户升级：已经配置过模型的，不自动弹出，直接记为完成；
  - 设置概览页底部有“重新打开新手向导”。
- 每一步都可以“上一步”或跳过；中途关闭窗口，已填好的内容照常保存，下次启动不再自动弹出。

### E. 设置窗口（`ui/settings_layout.py`、`ui/settings_window.py`、各 `*_page.py`）
- 只换样式：左侧导航加图标，选中项用泡泡蓝底；卡片、按钮、输入框按 A。
- 概览页：
  - 顶部是进度横幅：“还差 N 步就全部准备好”，带进度条和立绘；
  - 下面是清单行：已完成的显示绿色对勾，可选的标“可选”；每行一个按钮直达对应页面；
  - 删掉已经过时的“即将推出”卡片（人格包、心情、生活等都已上线）。
- 自动保存：
  - 每个控件改动后防抖约 500ms 再保存；
  - 输入不合法时（比如模型路径无效、QQ 号格式不对）不保存，在控件旁边给出说明；
  - 底部状态显示“✓ 已自动保存 · HH:MM”，保存失败时显示原因；
  - 原来“点保存才生效”的逻辑（例如切换声线、重启语音）改成“改动后生效”，并确认不会因为反复触发而重启服务。
