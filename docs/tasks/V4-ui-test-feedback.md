# V4-UI 实测反馈

Codex 负责实现，Claude 审查。共享文件 `ui/main_window.py` 的修改限于聊天入口与向导、设置的窗口管理。人格试聊需与正式聊天历史、关系记忆隔离，保留现有用户的数据。

用户补充要求在聊天窗口删除具体消息和记忆。由 Codex 修改共享文件 `storage/database.py` 的读写方法，使用现有表，按角色、聊天频道和选中记录的 ID 删除。

## 真机走查

1. 从托盘打开设置，再从设置重开新手向导。分别最小化，从 Windows 任务栏的鲸娘图标恢复窗口。
2. 在“声音与通话”选择已配置的 MiniMax 云端声线，切换到“电台主持”并试听，关闭设置再打开，核对音色。候选 ID 取自 [MiniMax 系统音色表](https://platform.minimax.io/docs/faq/system-voice-id)。
3. 在聊天面板打开“会话 → 聊天记录与记忆”。用测试文字发送两条同文消息，选择其中一条删除。再切到“记忆卡”选择要忘掉的事实。两种操作均需确认。
4. 在“会话 → 人格试聊”选择一个人格，连聊两轮，再切换到另一个人格。检查试聊从空白开始，正式聊天仍可查看。
5. 打开“关系与心情”，等待一次聊天或 QQ 互动改变心情，查看原因、进度条与最近事件是否自动更新。
