## 一、社交语境与攻击意图（六个问题）

**线索抽取**（`relationship/intent.py`，确定性、不调模型）：只给大脑看依据，不替她下结论。
- 针对谁：
  - @ 了谁（她 / 别人 / 全体）、引用回复的是谁的消息；
  - 第二人称"你 / 你们"；提到她的名字或"她 / 这 AI / 机器人"；
  - 最近和她说话的人（T15 的接话判断）。
- 谁的话：
  - 引号或书名号里的内容；
  - "X 说 / 他们说 / 网上说 / 原话 / 转 / 截图"这类转述词；
  - 引用回复的是别人的消息。
- 语气：
  - 脏话和变体词表：谐音、缩写、拼音首字母、中英混写，只放一般脏话，不放针对群体的蔑称；
  - 阴阳怪气标记："呵呵 / 好家伙 / 不愧是 / 您 / 就这 / 急了 / 破防 / 啊对对对 / 🙂 / 🤡"等；
  - 玩笑软化："哈哈 / 笑死 / 狗头 / doge / 开玩笑"。
- 前面发生了什么：她上一条说了什么、这条是不是紧接着她；最近有没有吵过（T15 `upset`）。
- 关系：T15 的相处底子（嘲讽 / 看语气 / 调侃）。
- 是否持续针对：这个人 24 小时内冲她来的负面事件次数，7 天内的次数；最近有没有在群里攻击别人。

**只在需要时**把线索写进提示：有脏词、阴阳标记、引用转述，或者针对对象不明。平常聊天不加，省词元。

**判断交给同一个大脑**：`<mind>` 增加 `at="me|other|all|none"`、`voice="own|quote"`、`tone="joke|tease|sarcasm|attack|neutral"`。

**记关系（确定性）**：
- 针对她、是他自己的话：
  - 认真攻击记 insult；
  - 反讽记 quarrel；
  - 调侃且让她开心记 friendly。
- 引用或转述：记一条 `report`，不扣分。
- 针对别人的攻击：记 `third_party_attack`。看到他欺负别人，她对他的印象和信任略降，幅度小。
- 持续针对：24 小时内第 3 次起提示她"他今天第 N 次冲你来了"。后台分析可以判 harassment。
- 后台关系分析同样输出 target / voice / tone：转述的不扣分，针对别人的改记第三方攻击。

## 二、社区信息获取与知识学习

**联网**（`community/search.py`）：
- 聊天接口是 DeepSeek 官方时，用 DeepSeek Search / Fetch（同一家、同一个密钥）；
- 否则用公开百科的 MediaWiki 搜索（中文维基、B 站游戏 Wiki）。

**隐私与费用**：
- 只搜"梗 / 黑话"这类词，不搜聊天原文；
- 含 5 位以上数字、是已知群友昵称、只有一个人说过的词不拿去搜；
- 每天搜索 / 读页有上限（默认 30 / 10 次）；
- 设置里可以关；测试不联网。

**学习**（`community/learner.py`，后台、按额度）：
1. **挖词**：允许的群里每攒够一段新消息，让模型列出疑似黑话 / 梗及它在这段话里的意思，记"出现过"（`lexicon_sightings`：哪个会话、什么时候、几个人用过）。
2. **推断**（MaiBot 两次推断）：用的次数到 2 / 5 / 12 / 30 次时，各推断一次——带上下文的意思和只看词本身的意思。不一致就算这个圈子的黑话，否则是普通词，不记。
3. **查来源**：可以联网时搜"词 + 梗 / 意思"，拿结果摘要让模型总结含义、语气（褒 / 贬 / 中性 / 反讽）、圈子、用法、出处链接，来源写进词义。
4. **演变**（Graphiti 双时间线）：新推断和当前词义对比，结果是相同 / 扩展 / 变了 / 群里另有用法。
   - 相同：加强；
   - 变了：给旧义标 `valid_to`，加新义并互相关联，旧义不删；
   - 群里另有用法：记成只在这个群用的义项。
5. **社区话题**：沿用 T12 的公开热词 / 热帖（B 站热搜词、V2EX 热帖）。可联网时每周搜一次"最近的网络热梗"，让模型抽出词和含义（带来源）。

**检索**：QQ 和桌面的提示里，在本条和最近几条消息里匹配已知的词，最多带 6 条：
- 当前含义、语气、圈子；
- 以前的含义（演变）；
- 本群的特殊用法；
- 来源。

提示里写明"懂就自然用，不解释笑点；拿不准别硬用"。

## 三、自然串梗与社区参与

- **群里的共同经历 / 内部梗**（`group_lore`）：后台关系分析顺带输出"这个群里大家都知道的事 / 叫法 / 内部梗"，带首次、最近、提到次数，有半衰期。群聊提示里带上这个群的几条。
- **玩梗说明**：
  - 合适时自然接梗、玩反话；按 T15 关系决定能不能调侃；
  - 一次最多用一个梗，不每句都用；
  - 不对陌生人用带攻击性的梗；
  - 说了梗不解释笑点，让懂的人会心一笑。
- **主动引入社区话题**：群里插话时，若有和这个群兴趣、共同经历相关的新鲜话题，提示里带上最多 2 条，"可以自然带出来，别播报"。频率仍走插话规则和公开回复额度。
- **界面**：新增"社区与黑话"页。
  - 学到的词：当前含义、圈子、语气、来源、在哪些群见过、演变历史；
  - 可删除；
  - 联网学习开关和今日次数。
