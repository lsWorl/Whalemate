# V4-2b 关系设定：她和你是什么关系由人格包决定

负责：Claude 实现，Codex 审查。分支 `task/v4-2b-bond`，叠在 #40（群聊修复）之上，因为两边都改 `bridge/service.py`。

## 需求

负责人 2026-11-11 16:54：
- 人设不要太固定。别人可能希望鲸鲸是他们的女朋友或者妹妹，而不一定是女儿和爸爸。
- 项目主要是一个情感框架，剩下的让用户自己拓展。

## 改了什么

- **`domain/bond.py`**：关系设定 `Bond`，作为人格包的一项内容（导入、导出、版本、切换跟着人格走，对应长期约束 5）。
  - 字段：
    - 预设（女儿 / 女朋友 / 妹妹 / 好朋友 / 自定义）
    - 她怎么叫你（叫法）
    - 说明里怎么指你（指代）
    - 群聊标记
    - 关系名
    - 相处方式
    - 外人冒充哪些身份会让她生气
  - 占位：文字里可以写 `{叫法}` `{指代}` `{标记}` `{关系}`，拼好整段提示词后统一替换。SillyTavern 卡的 `{{user}}` / `{{char}}` 也替换。
  - 安全：称呼、标记里去掉【】和换行（群聊靠行首【标记】认你，不能被拼出假标记）；冒充词只留文字和 `|`，不接受正则符号。
- **提示词不再写死“爹”**：
  - 桌面上下文（`ContextService`）：关系说明放在人设后面，全文替换占位。
  - QQ 场合说明：群聊、私聊、主动消息。
  - 外人规则、名单、冒充规则：外人自称是这个身份时，记一条越界、让她生气。“我是你爹”这类占便宜的说法仍然算。
  - 聊天卡、办事时的人设、人格编辑页的预览。
- **群聊记录的本人标记**：
  - 新记录按当前关系打（例如【对象】）。旧记录里的【爹】照样认。
  - 去掉群友昵称里的【】，外人不能起个“【爹】某某”的昵称冒充。
- **记忆统一写“用户”**：群聊整理记忆时，用户本人的事写成“用户…”，不写“爹…”。换人格、换关系后记忆照样成立（长期约束 2）。
- **内置鲸鲸升到人格包第 7 版**：
  - 角色设定和说话风格里的“爹”换成 `{指代}` `{叫法}`；原来那段关系描述挪进 bond，预设是女儿，内容和原来一样。
  - 没改过内置人格的用户升级后行为不变。改过的不覆盖（沿用人格包升级规则）。
  - 第 6 版原文留在 `older` 里。
- **人格编辑页**：新增“和你的关系”。选预设会自动填好各项，之后都能改；选“自定义”时不改现有内容。
- **QQ 设置页文案**：不再写“她管你叫爹”。
