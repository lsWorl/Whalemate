## 一、说了不回还在回

记录里：
- 16:54 "懒得搭理你了" → 对方回一句，她连发三条（"回你归回你""懒得搭理归懒得搭理，这两件事不冲突"）；
- 17:06 "那你自己扣着玩吧，不奉陪了" → 13 秒后对方发"小糖人"，她又回两条；
- 17:21–17:24 私聊里对方连刷二十多条 "fw"，她先后说了 5 次"不奉陪了 / 不回了 / 我不接"，每次都接着回。

原因：回不回完全交给模型，提示里只写了"不想理就不说"。模型嘴上说不理，下一条来了照样生成。

改法（`bridge/stance.py`，确定性，不靠模型自觉）：
- **说到做到**：她发出去的话里有"不奉陪 / 懒得理 / 不回了 / 你自己玩吧"这类意思时，这句发出去以后 10 分钟内，这个人的消息只记进聊天记录、不回、不调模型。群里 @ 她、不 @ 她、私聊都一样。一天内再犯，时间翻倍（20、40…最多 120 分钟）。
- **复读刷屏**：同一个人两分钟内把同一句话发到第三遍，直接不理 5 分钟，不用她先说话。
- **来服软**：对方说"对不起 / 我错了 / 不闹了"这类话，提前结束，这条照常交给她，提示她"原不原谅你自己定"。
- 提示里也写明：说了就真的收不到他的消息，所以没打算走就别说。
- 只管外人，爹不受影响。"人物关系"页能看到"不理他，还剩约 N 分钟"，有按钮可以手动解除。

## 二、好感度看不出作用

记录里：同一个人从 16:39 骂到 17:24，她从头到尾每条都认真回两三句俏皮话，和对普通群友没有区别。好感分数在降，但行为上看不出来。

原因：好感只变成提示里的几句话（"冷淡、回得短"），模型基本没照做。

改法：按关系分三档，每档有**确定性的**差别，让分数直接变成看得见的行为。

| 档 | 条件 | 行为 |
| --- | --- | --- |
| 热络 | 综合关系 ≥ 65，且没在生他的气 | 条数不限，可以多聊、开玩笑 |
| 一般 | 其他（包括没聊过的人） | 一次最多发 3 条 |
| 冷淡 | 好感 < 25，或今天已经冲她来了 3 次 | 一次只发 1 条，提示要求十个字以内；今天冲她来 3 次以上时，有一半的消息已读不回；5 次以上不打招呼直接不理 15 分钟 |

- 每档在提示里有对应的一段（"你现在对他很冷淡 / 跟他不熟 / 跟他挺熟"）。
- "人物关系"页选中一个人，第一行显示"现在的态度"和今天冲她来了几次。
- 查梗之后的回答不截条数（那是在回答问题）。

## 三、回得不像真人

记录里的典型句子：
- "啧，会个词就赶紧掏出来显摆""原批这词从你嘴里说出来 / 真是一点都不意外""糖完了这种话你翻来覆去说，除了它你也拿不出别的来了"——在评论梗这个词本身，而不是接梗；
- "不过看你这反复确认的劲儿，破防的可能不是我""这不就自己打自己脸了，刚还让我看你脸色当爹呢，转头又来一句玩原神玩的"——每句都是完整的俏皮话、分析对方，像写段子；
- 几乎每次都是两三条。

改法（提示）：
- 外人：绝大多数时候就一小句，几个字到十来个字；不排比、不总结、不分析对方、不复述对方的话再点评，不是每句都要占上风；
- 别人拿梗损她：不评论、不解释那个词，用梗回梗或顺着接一句；
- 词库和查梗的说明里也加了"别评论或解释这个词本身"；查到之后"接一小句，不讲出处来历"。

同时修了记录里的两个错：
- **把内部编号叫出来**（16:42 "勾#11，一句一条才像发消息啊"）：发出去之前去掉昵称后面的 `#数字`，提示里也写明不要写出来。
- **回 A 的时候把 B 没回的话补着回**（16:42 引用的是勾的消息，内容却在回 tangle 的"糖完了""你是 ai 吧"）：提示写明只回这次跟她说话的这个人、这一条。

## 四、标点还是多

记录里：T19 留了"长句保留一个逗号"，结果大部分回复都带逗号（"问你啊你自己说的，我哪知道""这句当理由,是不是有点单薄"）。

改法（`expression/segments.py`）：和外人聊**完全不用逗号、句号、分号**。
- 这些地方要么另起一条消息，要么两小段很短（合起来不超过 10 个字）时直接连着写；
- 英文逗号同样处理（前面是中文时）；"1,000"这类数字不拆；
- 问号、感叹号后面还有话时，标点留在前半句，后半句另算；
- 问号、感叹号、省略号、"？？？"、顿号、引号里的内容不动；像文档的长回复不动；
- 条数由第二节的上限管，不会因为拆逗号刷屏。
