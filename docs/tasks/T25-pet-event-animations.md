# T25 看手机、花 Token 动画接上真实事件

T24 的视频形象已经有 `phone`（看手机）和 `token`（花 Token）两个姿势，各自带进出过渡，但目前只能在预览和“做个动作”菜单里看到。本任务把它们接到真实事件上。

## 要做的事

1. **QQ 来消息时看手机**：QQ 桥收到发给鲸鲸的消息（主人私聊、群里被 @ 或命中话题）时，桌宠播放 `phone`，持续几秒或直到开始回复。之后回到当前状态，正在说话就回到说话。
   - 同一时段连续来消息时，不要每条都重新播放进入过渡。
   - 深夜免打扰、静音时是否播放，按 `pet/behavior.py` 的 `QUIET_KEYS` 规则决定。
2. **词元用量超阈值时花 Token**：`usage/meter` 记录一次调用后，若单轮或当日用量超过阈值，播放一次 `token`。
   - 阈值放进设置，先给合理默认值，例如单轮 2 万词元。
   - 每天最多提示若干次，避免办事长任务里反复播放。
3. 两个都以状态机事件的形式进入 `pet/state.py`，优先级低于拖动、掉落、出错，高于待机。

## 涉及文件

- `pet/state.py`：新增事件和姿势优先级。
- `ui/desktop_pet.py`：响应事件。
- QQ 桥的消息入口。
- 用量计量的回调。
- `ui/main_window.py` 是共享文件，按 AGENTS.md 需先与 Codex 约定改动范围。

## 验收

- 单测：状态机在两种事件下的姿势和恢复；阈值、每日次数、深夜规则。
- `tools/smoke_pet.py` 增加两项自检：模拟一条 QQ 消息和一次超阈值用量，确认桌宠先进入对应姿势，再回到原状态。
- 负责人真机：真实 QQ 消息到达时看手机，跑一个长任务时出现花 Token。

依赖：T24 合入（默认形象带有 phone、token 姿势）。
