# T19：对外人更像真人——被使唤时按真人的方式回、少用标点

负责方：Claude 实现，Codex 审查。分支 `task/t19-human-outsiders`，**叠在 `task/t18-social-community`（PR #20，未合入）之上**：用到 T18 的词库和联网搜索。

需求来源：负责人 2026-11-10 13:51——
"希望 AI 对外人的时候更加拟人，除了主人以外要是问她'去帮我查下这是什么梗'，这种按真人的形式进行回复；
和其他人对话的时候尽量不要用标点符号，可以参考真人在 QQ 中的对话形式。"

## 一、外人使唤她办事

范围：QQ 上除了爹以外的人（群友、非爹的私聊），被 @ 和不 @ 但在跟她说话两条路径都生效。爹让她办事照常，不走这里。

- **认出来**（`bridge/favor.py`，确定性、不调模型）：
  - "帮我 / 替我 / 给我查 / 去搜一下 / 能不能帮…"这类使唤；
  - "X 是什么梗 / 啥意思 / 啥来头"这类问梗。
- **怎么回交给同一个大脑**，提示里写明：
  - 她不是他的助手，也不是搜索引擎；帮不帮、帮到什么程度，看关系和心情；
  - 关系不错就顺手帮，用自己的话说个大概，拿不准就说"好像是"；一般或不熟可以只说自己知道的，或者让他自己搜；没好感就不帮或不理；
  - 不知道又没查到就说不知道，别编；
  - 不用助手腔：不说"好的""我来帮你查""以下是""根据搜索结果"，不列点、不贴链接。
- **要不要替他查，由她自己决定**（T20 改动：第一版是程序按关键词替她先搜，现在统一成她自己写 `<mind lookup="词"/>` 才去搜，见 `docs/tasks/T20-community-gaps.md`）。没好感的人她可以直接拒绝，不花搜索。
- **指代不清**（"查下这是什么梗"）：没有词可搜；提示她能从上文看出来就直接接，看不出来就像真人那样问一句"哪个"。

## 二、和外人聊尽量不用标点

范围：群聊（包括在群里回爹，群里的说话方式要一致）和非爹的私聊。和爹私聊、桌面不变。

- **提示**：句尾不加句号逗号；两个短句直接连着写或另起一条，长句读不通时才用一个逗号；真问才用问号，感叹号少用；"？？？""。。。"这类带情绪的可以；正经讲一段长内容时标点照常。
- **发出去之前再收一遍**（`expression/segments.py` 的 `qq_segments(casual=True)`，确定性）：
  - 句尾的句号、逗号、顿号、分号去掉；
  - "，"也当作可能分两条的地方，但比"。"更不容易拆（概率减半），免得刷屏；
  - 合在一条里时，两小段加起来不超过 10 个字就直接连着写（"嗯知道了"），更长才留一个逗号；
  - 问号、感叹号、省略号、引号里的内容不动；
  - 像文档的回复（代码、列表、600 字以上）原样。
- 不用空格代替标点：负责人 2026-11-09 明确不要"哟 逆天"这种写法。

## 不做

- 不改她的身份底线：仍然不明确声称自己是真人。
- 不给外人开工具、文件、电脑操作这类干活能力；这里只是聊天里顺手搜一个词。
- 搜到的内容不自动写进词库（词库仍由 T18 的后台学习按来源和对比流程写）。
- 不动共享文件（`main_window`、`database`、`config`、`pyproject`）；没有新表、新依赖、插件不用升级。
