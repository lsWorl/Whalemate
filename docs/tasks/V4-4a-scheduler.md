# V4-4a 统一主动调度（阶段三第一步）

负责：Claude 实现，Codex 审查。分支 `task/v4-4a-scheduler`，从 `task/v4-2b-bond`（含 #42、#43，见 #45）拉出。schema 12→13。

## 为什么

以前问候、心事各自定时，彼此不知道对方说过没有：刚问完早安，可能又冒出一件心事；他没回，也照样接着发。
计划书 v4 功能四要求先有统一的主动行为调度：调度器决定要不要开口、说哪一件，模型决定说什么。

## 做了什么

- **`brain/scheduler.py` ProactiveScheduler**：所有主动开口都先过这里。
  - 门槛：总开关、安静时段、专注模式照旧；他 3 分钟内刚说过话不插嘴。
  - **每天上限**：默认 5 次，追问也算（`proactive_daily_limit`）。
  - **两次间隔**：默认 90 分钟，再乘关系节奏（`proactive_gap_minutes` × `proactive_pace`）。“算了”或被晾着的那条，从放下的时候起算间隔。
  - **没回不开新话题**：上一句还没回时，45～90 分钟后（每条消息固定一个时间，重启也一样），如果他人在电脑前（闲置不到 10 分钟），60% 撒娇追一句（意图里带上她刚才说的话，只说一句、别质问），40% 自己“算了”。一个话题最多追一次。
  - **他回了**：主动消息之后他在桌面或主人 QQ 私聊说了话，记为 answered。
  - **太久没回**：3 小时没回记为 ignored，加一点“被冷落”的心情（力度 0.4），一件事只记一次。之后可以聊别的。
  - **先后**：
    1. 今天是特别的日子、还没提过、他今天也还没来 → 主动去说（陪伴日期，具体提哪些由聊天上下文带上，说完记为已提）；
    2. 心里惦记的事；
    3. 早晚问候 / 闲聊。
- **`outreach_log` 表**（schema 13）：每次主动开口一条，记来源、渠道（桌面 / QQ）、状态（sent / answered / followed / let_go / ignored）、追问的上一条。
- **桌宠接入**：`MainWindow._proactive` 改成问调度器，几种主动消息不再各管各的。
  - 桌面：真说出来（状态 complete）才记进调度记录。
  - 走 QQ：发送成功才记。
  - 失败时心事放回待送达，纪念日和问候的占位放回去。
- **设置**：“主动与提醒”加“每天最多主动找你 N 次，两次之间至少隔 N 分钟”，并说明追问规则。

## Codex 第一轮（b8bee45）三项 P2 的修复

1. **QQ 回执到之前重复追问**：选中要说的那一刻先在 `outreach_log` 占一条 `pending`（`reserve`）。桌面说完、QQ 插件回执成功后确认（`confirm`）；没说成就撤掉（`release`）。
   - `pending` 计入今天的次数，也挡住下一次开口。
   - 半小时还没确认的当作没发出去（程序中途退出之类）。
   - 回执来得比这还晚时照实补记。
   - `MainWindow` 的发送部分拆成 `_deliver_outreach`，测试直接走它。
2. **3 分钟不插嘴漏掉主人 QQ 私聊**：调度器自己从 desktop 频道（桌面和主人 QQ 私聊都记在这里）取最近一次用户说话的时间，和桌面输入的时间取较近的那个。
3. **间隔设置对追问无效**：追问也要满足“两次之间至少隔 N 分钟”。间隔设得比“3 小时没回就放下”还长时就不追问。

新增 `CodexRoundOneTests` 4 项覆盖以上三项，以及“失败撤掉占位、过期占位作废”。

## 怎么验证

`tests/test_scheduler.py`（可控时钟和随机数）覆盖：
- 没回不开新话题，回了以后等够间隔；
- 他不在电脑前不追问；追一句、只追一次、3 小时没回记小委屈、之后能聊别的；
- 自己算了，间隔从放下时算；
- 每天上限、第二天重新算、刚说过话不插嘴、安静时段、总开关；
- 纪念日优先于心事、同一天只主动一次；他今天来过就不专门去说。

桌宠冒烟检查（`ui/pet_smoke_check.py`）改为让调度器给出那件心事，检查桌宠接住、说出来、记进 `outreach_log`（新增检查项 `outreach_logged`）。
