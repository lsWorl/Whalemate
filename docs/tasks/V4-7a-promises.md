# V4-7a 约定

Codex 实现、Claude 审查和合并。对应计划书 v4 功能七。任务从已合入 #58 的协作基线开始。

约定按人物、角色及原会话管理，使用本地时间或下次交谈条件。统一调度负责投递，保留桌面、已绑定主人 QQ 私聊与原群的界限。共享文件涉及 schema、聊天控制器、主窗口与桥接发件箱。复用现有 Python、SQLite 和 Qt 依赖。

## 记录和投递

schema 15 → 16 新增约定表，补记 QQ 发件箱目标。每条保存角色、人物、原会话、来源渠道、轮次、内容、时间或条件、状态和修订版本。聊天只识别用户发起的同轮公开输出。代码示例保留，协议标记在显示前剥离。取消、失败、群聊静默和第一次查梗的中间轮次不写约定。无法解析的本地时间会在同一轮补问。用户说“不用提醒了”时只取消当前人物、当前场合唯一待提醒的那项，多项时问清楚。

“下次聊天”在同一个人再次在原会话发言时满足，也支持“聊到：关键词”。到点或条件满足后排进统一调度。安静时段、未获回应、间隔和每日上限顺延提醒。只有约定明确附带截止时间时才过期。“设置 → 关系与心情 → 我们的约定”可改内容、时间或条件、截止时间，也可取消。

桌面在展示首段前持久确认，意外退出时以避免重复投递为先。QQ 复用领取与回执，明确失败可重试，部分送达算已提醒，未知结果保留占位。群约定使用随项目提供的 AstrBot 插件 0.11.0，群号只进群投递字段。旧插件仍可接收原有私聊消息。插件不可用或原群取消授权时，该群约定继续等待。主人的私聊目标在领取前再次校验当前绑定。
