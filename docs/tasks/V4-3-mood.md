# V4-3：持续情绪、小脾气与撒娇（计划书 v4 功能三）

负责：Claude 实现，Codex 审查，负责人在 Windows 实机上验收。分支：`task/v4-3-mood`，从 `collaboration-baseline` 拉出。

## 要做成什么

她的心情会延续一段时间，不再每句话都从平静开始。被冷落会委屈，被欺负会回怼或闹脾气，被哄会慢慢消气，开心时会撒娇。

## 设计

- **数值**（`domain/mood.py`）：四种情绪 happy / shy / sad / angry，各有一个强度（0～100），名字沿用形象、语音、表情包已有的心情词。
  - 强度按半衰期回落：开心 3 小时、撒娇 2 小时、委屈 6 小时、生气 4 小时。
  - 强度达到 20 才算有这个情绪；达到 65 算“很”。
  - 事件让强度上升。被哄、道歉按**比例**压低（道歉减掉约 45% 的生气），所以是慢慢消气；只有设置里的“哄好她”会直接清零。
  - 以上全是第一版默认值，按体感调整。
- **人格的情绪倾向**（功能二的两个滑块）：
  - “容易不高兴”：负面事件的力度乘以 0.6～1.4；
  - “消气快”：负面情绪的半衰期乘以 1.5～0.5，被哄的效果乘以 0.5～1.5。
- **事件来源**：尽量不额外调用模型。
  - **同一轮的 `<mind/>`**：在 `chat_controller._after_turn` 里，复用她自己对“冲谁、是不是转述、玩笑还是认真、让她高兴还是不爽”的判断：
    - 转述别人的话（voice=quote）、在说别人（at=other/all/none）：不算冲她；
    - attack → 被骂；sarcasm → 被阴阳；toward ≥ 1 → 被夸，feel 里带害羞、撒娇、喜欢之类的词时算被说喜欢；
    - 力度按 toward 的大小折算。群聊打五折，QQ 私聊打八折。
  - **用户消息兜底**：道歉、喜欢、谢谢、骂人、难过这几类明显的词，按七成力度记。
  - **久别**：桌面上隔 20 小时以上才来，记一次“好久不见”。有点开心，同时按隔的天数带一点委屈（最多 30），提示词要求不指责对方。
  - **办成事**：办事完成后记一次“一起做成了事”，开心一阵。
  - **手动**：设置里的“哄好她”，把委屈和生气清零。
- **存储**：schema 10→11，新增 `mood_state`（各情绪的强度和时间）、`mood_events`（最近 200 条，界面显示“为什么”）。旧表不改。
- **怎么表现**：提示词里的“当前心情”改成程度 + 原因 + 怎么表现：
  - 很生气时可以语气冲一点、回得短一点，或者说暂时不想说话；
  - 委屈时想被安慰，但不指责对方；
  - 撒娇时可以黏人一点。

  同时**明确写出**：对方求助、办事、涉及安全的事照常认真回应。心情词同步写回 `emotion_state.mood`，形象、语音语气、表情包选择这些现有逻辑照常使用。
- **和关系分开**：心情事件不改好感、熟悉、信任。这些分数仍由关系系统按事件另算，吵一次架不会把好感清零。
- **界面**：设置 → 关系与心情，最上面一张“她现在的心情”卡片：一句话说明当前心情和原因、四种情绪的强度条、最近 6 件影响心情的事，以及“哄好她”按钮。

## 这一版没做

- “分享没人理”的委屈：要等功能四（她主动分享）完成后接上。事件类型 `ignored` 已经预留；她在 `<mind/>` 里写“委屈”时也会记这一类。
- “回得慢一点”：目前只通过提示词表现为回得短，没有加真实的延迟。
