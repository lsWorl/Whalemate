# V4-8b 鲸鲸默认声线（MiniMax，有感情）

负责：Claude 实现，Codex 审查。分支 `task/v4-8b-whale-voice`，叠在 #39（V4-8）之上。

## 需求

负责人 2026-11-11 16:05："希望鲸鲸的默认声音就是网上 AI 视频的那种声线，需要富有感情"。

网上流行的鲸娘 / 大肥鱼声音，大多是网友拿参考音频训练出来的少女音（GPT-SoVITS、RVC 等），来源和授权不明，不能直接用（计划书 v4 “大肥鱼声线”一节）。
这里按同一种感觉——少女感、软糯、带一点慵懒和小傲娇——在正规服务的音色库里选，并且让声音跟着情绪变化。

## 做法

- **声线属于角色**：`domain/voice_profile.py` 里写鲸鲸的声线设定：
  - 文字描述；
  - MiniMax 默认音色和候选音色；
  - 默认模型 `speech-2.8-hd`（HD 更有感情）。

  换服务时按同一份描述选音色（长期约束 1、4）。
- **MiniMax 语音客户端** `speech/minimax_client.py`：
  - 接口和请求：`POST {账户地址}/t2a_v2`，要 24 kHz 单声道 WAV（hex 返回）；中文用 `language_boost=Chinese`。
  - 安全：不跟随跳转，可随时取消；报错只给错误码和中文说明，不带响应全文和 Key。
- **有感情**：MiniMax 默认按台词内容自动选最自然的情绪（官方文档写明），所以平静、撒娇时不指定；开心、委屈、生气这类明显心情时显式指定 `emotion`。
- **默认生效**：
  - 模型页没有配语音合成时，有 MiniMax 账户就用鲸鲸的默认声线。它和聊天共用一个 Key，不用另配（`ModelRouter.default_voice`）。
  - 模型页明确配置的音色优先。
  - 朗读方式只在第一次自动切到“云端声线”：条件是用户从没选过朗读方式，或选的是系统朗读（`voice_profile_setup` 标记）。之后尊重设置里的选择。
  - 云端失败时照旧退回本地朗读（V4-8）。
- **换音色**：设置 → 声音里，朗读方式选“云端声线”时可以从候选音色里换（存 `voice_choice:<角色>`），“试听声线”试听当前选中的。模型页也可以手动填 MiniMax 音色 ID，新增了 MiniMax Speech 2.8 HD / Turbo 两个预设。

## 自动接入与试听规则（Codex PR #41 审查后）

- 只对从没存过朗读方式的库自动切到默认声线，且只切一次；库里已存的任何朗读方式（包括旧库的 system）都不动。
- 设置页没动朗读方式时保存不写入它，保持“未设置”。
- 试听只用临时的候选音色，不写库；点“保存”才生效，“取消”保持原音色。
- FixedRouter（测试 / 诊断 / 预览）不提供云端声线，界面退回本地朗读。
