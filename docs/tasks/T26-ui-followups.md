# T26 #67 审查跟进与去掉男声音色

负责人 2026-11-16 要求把 #67 审查中的四条非阻塞建议另开任务处理，并删掉男声音色。Claude 实现，Codex 审查。本分支基于 #67（`task/v4-ui-test-feedback`），#67 合入后改基到 `collaboration-baseline`。

## 改动

1. **整理期间删一条消息，不再让整批作废。**
   - 去掉 `MemoryService.analyze` 里检查整批原话的 `still_present`。
   - `upsert_memory` 本来就在写事务里核对每条记忆自己的 `source_ids`：来源被删的记忆不写入，同一批里其他仍有原话支撑的记忆照常保存。
2. **同一事实再次被记住时，合并来源。**
   - `upsert_memory` 命中已有事实时，把旧来源与新来源合并、去重，最多保留最近 50 条（语义召回只认 100 条以内的来源列表）。
   - 只合并与新来源同一频道的旧来源：桌面和群聊混在一起，`semantic.origin_for` 会判不出可见范围。
   - `delete_chat_messages` 改为先从记忆卡和存档里去掉被删的来源：还有其他原话支撑就保留，没有了才删除，同时清掉对应的心事和本地向量。阶段摘要概括的是一段对话，仍然整段删除。
3. **删记忆不打断回复。** `ChatRecords` 只在删消息时调用 `interrupt()`，忘掉记忆卡不打断正在进行的回复，下一轮自然不再引用。
4. **主窗口复用心情服务。** `_refresh_chat_mood` 只在第一次调用时创建 `MoodService`，之后复用同一个实例。`MoodService` 没有缓存状态，可以复用。
5. **去掉男声音色。**
   - 鲸鲸的 MiniMax 候选里去掉温润青年、不羁青年、幽默大爷、电台男主播（`REMOVED_MALE_VOICES`），保留 10 个女声。
   - 新闻主播改标为“新闻女声”，对应 MiniMax 中文文档里的名称，需负责人试听确认。
   - 以前在设置里选过这些男声的：
     - 默认声线的路由本来就不采用候选外的音色，会回到软糯少女。
     - 如果当时生成了角色级绑定，设置页显示为“自定义音色 · ID”，可以在下拉框里换回女声。
   - 模型页里手动配置的绑定不会被强制改写。

## Codex 第 1 轮审查后的修复（`dd032f1` 之后）

1. **更正后又删掉更正那条消息，更正内容仍被记着。** 现在只有同一版本（内容没变）才合并来源。内容被更正时，新版本只认这次的原话，删掉更正那条消息后，更正内容从卡片和存档里一起消失。卡片不会自动回退成旧内容，旧版本留在存档里。
2. **先删第一次提到的那条消息，存档被误删。** 同一版本再次被提到时，把存档里这一版的来源同步更新为合并后的来源。新增测试覆盖两种删除顺序。
3. **`source_ids` 传迭代器时来源被清空。** 现在在入口处转成列表一次，校验、合并、写入都用这一份。
4. `docs/implementation_status.md` 补了 T26 的记录。
