# V4-6b 语义召回与阶段摘要

Codex 实现，Claude 审查。共享文件涉及 SQLite schema、数据库删除事务、聊天上下文和设置页。云端使用标准库 HTTP 和 SQLite，没有新增依赖。

## 开启与关闭

在“模型与 Key”添加百炼（北京）、智谱或自定义 OpenAI 兼容账户。自定义模型勾选“文本向量”。在“记忆与心事”选择模型和维度，核对接收地址并确认。默认推荐百炼 text-embedding-v4、1024 维。只有用户确认且账户有 Key 才会开始传输。开启云端后，记忆和你说的话会发给所选厂商计算向量。可随时关闭，或在用量页设置每日向量额度。地址、模型或维度改变后需要重新确认。

## 召回与隐私

- 聊天先取已有记忆卡，再将相关任务、FTS5 旧消息、存档和同义记忆按相关度合并。相同事实键或内容相近的候选去重，最多六条，旧事带不确定措辞。阶段摘要和召回一起计入整份请求预算，放不下时可整段裁掉，保留人格和当前发言。
- 索引以角色、事实键、账户、地址、模型、维度和内容哈希校验。后台每批至多十条，按原频道分别调用。更新中断可从已提交的批次继续。模型变更、缺 Key、断网、超额、索引未就绪时继续用关联和关键词查找。临时故障按 3 秒起的退避重试，上限五分钟。调用计入“记忆向量”日用量。
- 消息编号用于查明来源。向量查询和阶段摘要只取同一角色、同一频道，绑定主人的 QQ 私聊沿用桌面主人频道。旧版无来源编号的 QQ 共享卡沿用原有可见范围，不会上传作向量。删除记忆在同一事务移除该事实的索引、存档和该角色的摘要，设置聊天水位。网络返回时重新检查事实内容、可见性和删除状态。
- 每频道最多每小时整理一批 16 条完整消息，保留最近 30 条原话进入常规历史。参与摘要的消息 ID 由本地选择，生成后重新核对后再写入。设置中可逐条查回原话。原文保留。摘要使用已有记忆整理模型和额度。旧版滚动摘要仍保存在原表，出现有来源的阶段摘要后优先使用新摘要。
