# T21：预置词库

负责方：Claude 实现，Codex 审查。分支 `task/t21-seed-lexicon`，基于 `task/t18-social-community`（含 T18、T19、T20）。

需求来源：负责人 2026-11-10 16:13 / 16:18——词库刚装上时是空的，要联网、等群聊积累一段时间才学得到；
先预置一批常用梗，主要是 B 站、游戏、二次元、抽象圈，"可以涵盖多些常用梗"；之后所有功能一起测试，并给出测试手册。

## 做了什么

- **数据**（`community/seed_data.py`）：288 组、336 个词（同一个意思的几种写法各算一个词）。
  - 圈子：抽象 112、游戏 71、二次元 67、B 站 53、通用网络缩写 33。
  - 每条有含义、语气（褒 / 贬 / 中性 / 反讽 / 自嘲 / 调侃）、用法。含义和用法是自己写的简短说明，不抄任何网站；
    出处只写到圈子这一层，没有逐条核对具体来源。
  - 不收：嘲讽真实人物的梗、针对群体的蔑称、涉政和色情内容；带攻击性的圈内称呼只收她需要听懂的少数几个，用法里写"听得懂就行，别拿来叫人"。
  - 不收和日常用语大面积重合的词（"确实""启动""毕业""钓鱼""离谱"等），免得平常聊天也被当成梗、提示里塞满无关说明。
- **安装**（`community/seed.py`，`app.py` 启动时调用一次，失败不影响启动）：
  - 装成通用义（作用域空），来源 `seed`（界面显示"预置"，提示里显示"常用用法"），可信度 0.55，比联网查到的 0.75 低；
  - 只装"这个预置版本新增的词"（设置 `community_seed_version`）：以后加词只补新的；**用户删掉的词不会在下次启动时又冒出来**；
  - 词库里已经有通用义的词（联网、手动、热梗）不覆盖；只有本群用法的词照样装通用义，检索时本群用法优先、通用义作补充；
  - 不联网、不调模型。
- **和已有流程的配合**：
  - 检索（T18）：一出现就带进提示，第一天就能用；
  - 当场查梗（T20）：词库里已有的词不再查；
  - 联网学到不同说法（T18 `learn_web`）：按对比结果更新，`changed` 时预置义标失效、被新义取代，旧义留作演变记录；
  - 后台推断（T18 `infer`）：已经有通用义的词，即使模型"带上下文和只看词本身意思一样"，也不会被降成普通词（之前会，因为模型本来就懂这些常用梗）。
- **测试手册**：`docs/testing/T18-T21-test-manual.md`。

## 不做

- 不从任何网站批量抓取词条；
- 不改表结构、不加依赖；插件不用升级（仍是 0.9.5）。
