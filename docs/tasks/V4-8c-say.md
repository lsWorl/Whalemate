# V4-8c 长回复口播版

Codex 实现，Claude 审查和合并。对应计划书 v4 功能八第 3 点。

通过桌面陪伴和办事提示词邀请模型在同一次回复中附带几句口语总结。正文照常流式显示，语音在回复结束时选择。第一段非空纯台词作为口播，其余完整口播段隐藏。代码示例和未闭合、超过 1200 字的候选保留原文。单轮口播按既有朗读上限裁至 300 字，每段最多 120 字。

口播保留在最终桌面事件或办事结果的临时字段中。气泡、字幕、存储与 QQ 输出使用正文。办事仅解析 Harness 的消息事件，并在工具调用处分开过程与最终结果。

离线验收覆盖整段和逐字、上下限、多个标记、代码、朗读开关、桌面、QQ 与模拟 Harness。真实模型是否选择附带口播和实际声线听感由负责人验收。
