# 阶段一实机测试手册（里程碑：能正常聊天）

对应 PR：#27（V4-1a）→ #28（V4-1b）→ #29（删除爱蜜莉雅）→ #30（V4-1c 模型页）。按顺序合并后，在 Windows 上测试。

会产生少量费用的步骤标了 💰。每一项做完在方框里打勾；不通过的写下现象（截图更好），反馈给 Claude。

## 0. 准备

- [ ] 拉取合并后的代码，`.venv\Scripts\python.exe -m pip install -e .[agent]`。
- [ ] **删除旧数据库**（表结构默认角色改了）：先打开桌宠 → 设置 → 存储位置，记下数据库位置；退出桌宠，把 `aicompanion.sqlite3` 移到别处备份。
- [ ] `.env` 里的 `LLM_*` 已经不再生效，可以留着也可以删；语音的 `SPEECH_API_KEY`、`QWEN_API_KEY` 仍然有效。
- [ ] 运行 `tools\run_checks.bat`，确认 `output\v2-check\unittest.log` 末尾是 `OK`，`smoke.log` 里 `"passed": true`。

## 1. 没配置模型时

- [ ] 启动桌宠：角色是鲸娘（大肥鱼），右键菜单里显示“未配置模型（离线模拟）”。
- [ ] 角色列表里**没有**爱蜜莉雅。
- [ ] 和她说一句话：回复是离线模拟的固定内容，不报错、不卡住。
- [ ] 设置 → 干活：“干活用的模型”一栏提示去“模型”页选择；让她办事时，气泡提示还没有配置办事模型。

## 2. 添加账户与 Key（设置 → 模型与 Key）

- [ ] 点“添加账户”，选 DeepSeek，粘贴 Key，确定。表格里 Key 一栏显示“已加密保存（可用）”，**看不到 Key 的任何字符**。
- [ ] 账户自动带上了 deepseek-flash、deepseek-v4-pro 两个模型（能在“聊天”下拉里看到）。
- [ ] （可选）用 DB Browser 打开数据库，搜索你的 Key：**搜不到**（只存了加密后的内容）。
- [ ] 退出并重新打开桌宠：Key 仍然显示“可用”（DPAPI 能解开）。

## 3. 聊天 💰

- [ ] 设置范围选“全局默认”，聊天选 `DeepSeek · deepseek-flash`（选了就自动保存，没有“应用”按钮）；“现在生效”一行显示 DeepSeek · deepseek-flash。
- [ ] 直接点右上角关闭设置再打开：刚才的选择还在，不会变回“未设置”。
- [ ] 再添加一个 DeepSeek 账户：名字自动变成“DeepSeek 2”，各下拉框里没有两个一模一样的选项。
- [ ] 点“测试聊天”：几秒内显示“聊天连接正常：……收到”。
- [ ] 关掉设置，右键菜单的模型标签变成 DeepSeek · deepseek-flash。
- [ ] 正常聊几句：回复速度和以前差不多或更快（默认已关闭思考），气泡和语音里**没有**推理过程的文字。
- [ ] 记一下首字大概几秒：______

## 4. 换 Key 立即生效 💰

- [ ] 模型页选中 DeepSeek 账户 →“修改 / 换 Key”→ 填一个**错误**的 Key → 确定。
- [ ] 下一句聊天：出现鉴权失败的提示（HTTP 401），桌宠不卡死，**不会**偷偷换成别的服务继续回复。
- [ ] 再换回正确的 Key：下一句就恢复正常，不用重启。
- [ ] “修改”时 Key 框留空直接确定：Key 不变，聊天照常。

## 5. 按角色单独设置

- [ ] 设置 → 角色：新建一个自建角色。
- [ ] 模型页“设置范围”选这个角色：各项都显示“跟随全局”。
- [ ] 给它单独选 `deepseek-v4-pro` 聊天；切到这个角色聊天，模型标签显示 deepseek-v4-pro；切回鲸娘仍是 deepseek-flash。
- [ ] 把它的聊天改回“跟随全局”：恢复成 deepseek-flash。

## 6. QQ 识图（需要 QQ 桥接在运行）💰

- [ ] 模型页“识图”选 `DeepSeek · deepseek-flash` 。
- [ ] 私聊发一张普通照片：她的回复能接住图片内容。
- [ ] 发一个表情包：她当作语气来接话，不逐项点评图片。
- [ ] 把“识图”改回“未设置”：再发图，她不再看图（不额外调用识图），聊天照常。

## 7. Breeze Blue 语音 💰

- [ ] 模型页“添加账户”选 Breeze Blue，粘贴 Key。
- [ ] 范围选“角色：大肥鱼”，语音合成选 `Breeze Blue · Breeze TTS 2`，音色填控制台里的 `voc_...`，语言选中文（自动保存）。
- [ ] 点“试听语音”：状态显示“语音合成正常：x.x 秒音频”，并且能听到声音；用量页里这次试听只记一次合成。
- [ ] 试听后朗读开关和朗读方式没有被改动。
- [ ] 设置 → 语音与互动：朗读方式选“Breeze Blue”，声线一栏显示刚才的音色（灰色不可改），保存。
- [ ] 打开朗读，聊几句：用 Breeze 音色逐句朗读；说话时能打断；口型跟着动。
- [ ] 改语速到 1.3 ：新句子明显变快（不会命中旧缓存）。
- [ ] 听感评价（是否自然、情绪是否对）：______

## 8. 办事（Harness）💰

- [ ] 模型页“办事”选 `DeepSeek · deepseek-flash` 。
- [ ] 让她做一件读文件的小事（例如“看看桌面上有哪些文件夹”）：正常完成。
- [ ] 让她在工作区里写一个文件：弹出确认气泡；拒绝后不执行，同意后执行。
- [ ] 中途说“停”：任务停止。
- [ ] （有 MiniMax Key 时）💰 添加 MiniMax 账户：“办事”下拉里有 MiniMax-M3.1-Flash 和 MiniMax-M3。选 MiniMax-M3.1-Flash，让她做同样的读文件小事：能完成；写文件仍会弹确认气泡。
- [ ] 把设置范围切到某个角色，只给它选 MiniMax 办事：这个角色用 MiniMax，鲸娘仍用全局的 DeepSeek。
- [ ] 办事模型旁边有灰色说明：只列出 Harness 能用的模型；全局默认对所有没单独设置的角色生效。
- [ ] 如果以前用过 DSH 命令行并保存过 Key：办事时用的仍是模型页里选的 Key（不会被 DSH 自己保存的旧 Key 顶替）。
- [ ] 她在回复或办事时打开设置、再关闭：回复和任务**不被打断**。

## 8.5 语音默认与朗读

- [ ] 删库后首次启动：朗读开关是关的，通话没开；设置 → 语音与互动 → 收音方式默认是“按住说话”，收音键默认右 Ctrl。
- [ ] 开启通话后不按键她不收音；按住右 Ctrl 说话，松开发送。
- [ ] 打开朗读，让她回复一段带文件路径、链接或代码块的话：不会把路径、文件名、网址和代码逐字念出来（读成“那个文件”“链接”“一段代码”），代码块后面的话照常朗读。

## 8.6 表情图库（设置 → 表情图库）

- [ ] 往图库目录里放几张自己的图，点“刷新图库”：状态直接是“可用”，来源显示“自己的图（自用）”，**不用**填作者、来源、含义。
- [ ] 模型页配好“识图”后打开表情图库：“识别含义中”的图几秒到几十秒后含义变成识图给出的描述。💰
- [ ] “导入图片”可以一次选多张。
- [ ] 按住 Ctrl / Shift 多选，或点“全选”，再点“停用选中”/“启用选中”：一次改完。
- [ ] 导入一份没写许可的素材清单：这些图显示“许可待确认”；选中后在“来源”里选“自己的图（自用）”，点“设为选中图片的来源”，变成可用。
- [ ] 以前就在图库里、显示“待审核 / 停用”的图：聊一句话或刷新图库后变成可用（之前手动停用过的仍是停用）。
- [ ] 以前用素材清单导入、写了原作者或来源的图：刷新图库后仍是“许可待确认”，原作者、来源、含义不变。
- [ ] 停用的图点“重新识别含义”：先不识别；重新启用后自动识别。

## 8.7 界面翻新

- [ ] 任务栏、托盘、聊天面板和设置窗口的图标都是鲸娘头像（不是 Python 图标）。
- [ ] 没配置聊天模型时，聊天面板顶部有黄色引导条；点“去配置”直接打开“模型与 Key”页。配好后引导条消失。
- [ ] 设置窗口左侧分为“她 / 能力 / 连接 / 系统”，第一页“概览”列出还差哪几步，点“去设置”能跳到对应页。
- [ ] 每一页上面都有一句说明；还没做的功能显示为虚线框的“即将推出”。
- [ ] 改了“声音与通话”“主动与提醒”里的选项，点“保存”后生效；点“取消”不保存。
- [ ] 聊天面板输入栏点亮“办事”，输入“看看桌面上有哪些文件夹”发送：她开始办事；发完“办事”自动熄灭，下一句回到普通聊天。
- [ ] 输入栏的“＋”是灰色的，悬停提示“即将支持：把文件交给她办事”。
- [ ] 整体观感：是否比原来清楚？哪一页还乱？______

## 8.8 人格包（阶段二·功能二）

- [ ] 设置 → 角色与形象：“人格”下拉里有“默认（内置）”（以前改过设定的，还会有“我改过的版本”，并且它是当前人格）。
- [ ] “管理 ▾ → 复制这个人格”，改个名字，在说话风格里写“说话特别傲娇”，点“保存这个人格”；点“预览她会怎么说”：回复是傲娇语气（💰 少量用量）。
- [ ] 点“设为当前”，回聊天面板聊一句：语气变了；名字、记忆、好感都没变。QQ 上也是新语气（如果接了 QQ）。
- [ ] 改几次后点“管理 ▾ → 历史版本…”，回退到某个版本：内容回来了。
- [ ] 世界书加一行“关键词：奶茶 / 内容：只喝冰奶茶”。聊奶茶时她记得，聊别的时不提。
- [ ] 导入一张 SillyTavern 角色卡（PNG 或 JSON）：生成一个新人格，字段对得上，里面没有 {{char}} / {{user}}，没有自动切换。
- [ ] 导出为本项目格式和 SillyTavern 格式：文件里没有聊天记录和记忆。
- [ ] 往角色设定里粘一大段（6000 字以上）：下面出现“内容偏长”的提示。
- [ ] 切回“默认（内置）”：恢复原来的性格。

## 8.9 持续情绪（阶段二·功能三）

- [ ] 和她说一句明显损她的话（例如“你好笨啊”，语气认真一点）：她回得有点冲。设置 → 关系与心情：显示“有点生气”或“很生气”，并写着原因。
- [ ] 接着随便聊一句别的：她还带着点情绪，**不会**马上恢复平静。
- [ ] 认真道个歉：她慢慢消气，不是一句话就完全好；再哄一两句才好。
- [ ] 生气时让她办事，或者问一个正经问题：照常认真帮忙。
- [ ] 夸她，或者说“抱抱”：心情变成开心或想撒娇。
- [ ] 设置里点“哄好她”：委屈和生气清零。
- [ ] 人格里把“容易不高兴”拉满、“消气快”拉到最低，再试一次：生气更明显，持续更久。
- [ ] 隔一天以上再打开她：她会说想你了、有点委屈，但不怪你。
- [ ] 心情不影响关系页上的好感数值（只有关系事件会改它）。

## 8.10 回复带语音（阶段二·功能八 第一版）

- [ ] 新库（或从没动过朗读开关）启动后，聊天面板上的“朗读”是亮的；设置 → 声音与通话 →“说多少”默认是“智能朗读”。
- [ ] 以前手动关过朗读的：启动后提示一次“现在可以让我开口说话啦”，“朗读”仍是关着的。
- [ ] 短回复（一两句）：整段念出来，文字先出来、声音紧跟着。
- [ ] 让她写一个带清单、表格或代码的长回复：只念开头、“我列了 N 条，第一条是……”“我做了张表”“一段代码”、要你做的事和结尾，最后说一句“剩下的写在气泡里”之类；整轮不超过一分多钟。
- [ ] 办事结果很长时同样只念重点。
- [ ] 她念到一半时你发新消息，或者按 ■：后面的不再念。
- [ ] 回复念完以后再发下一句，或者挂断通话、退出再打开：上一条回复**不会**显示“被打断”。
- [ ] 没配云端声线时把朗读方式选成 Breeze Blue 或千问：状态栏提示“这一轮先用本地朗读”，用系统声音念完，回复不报错。
