# 阶段一实机测试手册（里程碑：能正常聊天）

对应 PR：#27（V4-1a）→ #28（V4-1b）→ #29（删除爱蜜莉雅）→ #30（V4-1c 模型页）。按顺序合并后，在 Windows 上测试。

会产生少量费用的步骤标了 💰。每一项做完在方框里打勾；不通过的写下现象（截图更好），反馈给 Claude。

## 0. 准备

- [ ] 拉取合并后的代码，`.venv\Scripts\python.exe -m pip install -e .[agent]`。
- [ ] **删除旧数据库**（表结构默认角色改了）：先打开桌宠 → 设置 → 存储位置，记下数据库位置；退出桌宠，把 `aicompanion.sqlite3` 移到别处备份。
- [ ] `.env` 里的 `LLM_*` 已经不再生效，可以留着也可以删；语音的 `SPEECH_API_KEY`、`QWEN_API_KEY` 仍然有效。
- [ ] 运行 `tools\run_checks.bat`，确认 `output\v2-check\unittest.log` 末尾是 `OK`，`smoke.log` 里 `"passed": true`。

## 1. 没配置模型时

- [ ] 启动桌宠：角色是鲸娘（大肥鱼），右键菜单里显示“未配置模型（离线模拟）”。
- [ ] 角色列表里**没有**爱蜜莉雅。
- [ ] 和她说一句话：回复是离线模拟的固定内容，不报错、不卡住。
- [ ] 设置 → 干活：“干活用的模型”一栏提示去“模型”页选择；让她办事时，气泡提示还没有配置办事模型。

## 2. 添加账户与 Key（设置 → 模型）

- [ ] 点“添加账户”，选 DeepSeek，粘贴 Key，确定。表格里 Key 一栏显示“已加密保存（可用）”，**看不到 Key 的任何字符**。
- [ ] 账户自动带上了 deepseek-flash、deepseek-v4-pro 两个模型（能在“聊天”下拉里看到）。
- [ ] （可选）用 DB Browser 打开数据库，搜索你的 Key：**搜不到**（只存了加密后的内容）。
- [ ] 退出并重新打开桌宠：Key 仍然显示“可用”（DPAPI 能解开）。

## 3. 聊天 💰

- [ ] 设置范围选“全局默认”，聊天选 `DeepSeek · deepseek-flash`，点“应用”；“现在生效”一行显示 DeepSeek · deepseek-flash。
- [ ] 点“测试聊天”：几秒内显示“聊天连接正常：……收到”。
- [ ] 关掉设置，右键菜单的模型标签变成 DeepSeek · deepseek-flash。
- [ ] 正常聊几句：回复速度和以前差不多或更快（默认已关闭思考），气泡和语音里**没有**推理过程的文字。
- [ ] 记一下首字大概几秒：______

## 4. 换 Key 立即生效 💰

- [ ] 模型页选中 DeepSeek 账户 →“修改 / 换 Key”→ 填一个**错误**的 Key → 确定。
- [ ] 下一句聊天：出现鉴权失败的提示（HTTP 401），桌宠不卡死，**不会**偷偷换成别的服务继续回复。
- [ ] 再换回正确的 Key：下一句就恢复正常，不用重启。
- [ ] “修改”时 Key 框留空直接确定：Key 不变，聊天照常。

## 5. 按角色单独设置

- [ ] 设置 → 角色：新建一个自建角色。
- [ ] 模型页“设置范围”选这个角色：各项都显示“跟随全局”。
- [ ] 给它单独选 `deepseek-v4-pro` 聊天并应用；切到这个角色聊天，模型标签显示 deepseek-v4-pro；切回鲸娘仍是 deepseek-flash。
- [ ] 把它的聊天改回“跟随全局”：恢复成 deepseek-flash。

## 6. QQ 识图（需要 QQ 桥接在运行）💰

- [ ] 模型页“识图”选 `DeepSeek · deepseek-flash` 并应用。
- [ ] 私聊发一张普通照片：她的回复能接住图片内容。
- [ ] 发一个表情包：她当作语气来接话，不逐项点评图片。
- [ ] 把“识图”改回“未设置”：再发图，她不再看图（不额外调用识图），聊天照常。

## 7. Breeze Blue 语音 💰

- [ ] 模型页“添加账户”选 Breeze Blue，粘贴 Key。
- [ ] 范围选“角色：大肥鱼”，语音合成选 `Breeze Blue · Breeze TTS 2`，音色填控制台里的 `voc_...`，语言选中文，应用。
- [ ] 点“试听语音”：状态显示“语音合成正常：x.x 秒音频”，并且能听到声音。
- [ ] 设置 → 语音与互动：朗读方式选“Breeze Blue”，声线一栏显示刚才的音色（灰色不可改），保存。
- [ ] 打开朗读，聊几句：用 Breeze 音色逐句朗读；说话时能打断；口型跟着动。
- [ ] 改语速到 1.3 并应用：新句子明显变快（不会命中旧缓存）。

## 8. 办事（Harness）💰

- [ ] 模型页“办事”选 `DeepSeek · deepseek-flash` 并应用。
- [ ] 让她做一件读文件的小事（例如“看看桌面上有哪些文件夹”）：正常完成。
- [ ] 让她在工作区里写一个文件：弹出确认气泡；拒绝后不执行，同意后执行。
- [ ] 中途说“停”：任务停止。
- [ ] （可选，有 MiniMax Key 时）添加 MiniMax 账户，办事选 MiniMax-M3：能完成同样的小任务；如果报“Harness 不支持”，记下原文。
