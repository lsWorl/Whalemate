## 退出与接续

- `<leave reason="想休息一会儿"/>` 可以跨 token 到达。回复的正文进入聊天、气泡和朗读，完整的桌面私聊 final 事件才携带退出意愿。等待期间有新回复、开通话、开始办事、出现审批或关掉开关，都会取消这次退出。留至少 1.5 秒展示告别，朗读最多等 5 秒。
- 重启后在设置的“办事 → 操作日志”选择暂停任务，核对步骤、填写剩余事项并确认。接续沿用原任务的审计编号，重新检查账户和权限。文件修改和有副作用的命令在执行前留指纹，接续时相同操作会被拒绝，新的操作仍待确认。
- 桌面未显示的主动消息和 QQ 未领取的投递按没说成结算，释放问候、心事、日期及生活分享的占位。已经展示一部分或 QQ 已领取但没有回执的记作结果未知，避免重复发送。迟到的真实 QQ 回执仍可对账。
