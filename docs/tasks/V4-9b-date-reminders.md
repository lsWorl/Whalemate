# V4-9b 纪念日提前提醒

Codex 实现，Claude 审查和合并。对应计划书 v4 功能九。

“我们的日子”在添加时可选提醒时机，已有日子可在表格中直接改。生日默认提前一天和当天都提醒，自定义纪念日默认当天提醒。选择不提醒的日子仍列在日历中。程序推算的节日、周年只在当天参与提醒。

统一调度按本地公历的明天检查用户日期，农历复用原有换算。提前提醒在主人私下轮次绑定后才取标题，使用当日占位和既有桌面显示、QQ 投递回执结算。schema 14 升到 15 时原位加列，保留日期 ID 和历史提及记录。

验收用临时数据库、可控时钟、离线模型和桌宠自检。真实主人 QQ 私聊与桌面使用体验由负责人验收。
