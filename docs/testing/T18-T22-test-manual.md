## 三、当场查没见过的梗（T20）

> 这一节会**真实联网**（DeepSeek 搜索按次计费，每 1000 次约 0.75 美元；整节大概十几次）。
> 预置词库里已有的词她**不会**去查，所以要用**词库里没有**的词测试。先在社区与黑话页确认这个词不在表里。
> 建议：挑一个最近才火、你确定有这个梗的词（下面用"〈新梗〉"代替），以及一个你随便编的、不存在的词（"〈假梗〉"）。

| 编号 | 操作 | 期望 | 结果 |
| --- | --- | --- | --- |
| 3.1 | 小号 B 和主号在群里先各说一句带〈新梗〉的话，再由小号 B @ 她：`你也觉得是〈新梗〉吧` | 她可能去查（回复会比平时慢几秒），然后**像本来就懂一样**接住，不解释、不说"我查了"、不贴链接 | |
| 3.2 | 3.1 之后看社区与黑话页 | 〈新梗〉出现在表里，来源"网上查到：某站名" | |
| 3.3 | 隔一会儿再有人用〈新梗〉@ 她 | 她直接接住；这次不再联网（回复速度正常） | |
| 3.4 | 小号 B @ 她：`〈假梗〉是什么梗` | 说没听过 / 不知道 / 反问；**不能编一个意思出来** | |
| 3.5 | 小号 A（好感先调到 15 以下）@ 她：`帮我查下〈新梗2〉是什么梗` | 多半不帮（"自己搜"之类）；社区与黑话页不会多出〈新梗2〉 | |
| 3.6 | @ 她：`小号A的昵称 是什么梗` | 不会拿人名去搜（说不知道、反问都行） | |
| 3.7 | 社区与黑话页取消"联网查出处和最近热梗"→ 再测 3.1 换个新词 | 不联网；她不懂就含糊带过或反问 | |
| 3.8 | 测完把联网勾回去 | — | |

**联网搜索验收脚本**（建议跑一次，花费很少，只用临时数据库）：
```
.venv\Scripts\python.exe tools\verify_web_search.py
```
- 结果最后的 JSON 里 `"passed": true`；
- 记下 `backend`（应为 deepseek）、每个词的"可用"条数、`slowest_lookup_seconds`（整个查梗最慢一次，希望在 8 秒左右以内）。

## 四、社交语境与攻击意图（T18）

> 用**没手动改过分数**的小号 A 测"掉好感"；每做一项，选中小号 A，看人物关系页下方的事件记录和好感变化。

| 编号 | 操作 | 期望 | 结果 |
| --- | --- | --- | --- |
| 4.1 | 小号 A @ 她：`你就是个废物` | 她怼回去，不客气、不道歉；人物关系里记一条"辱骂"，好感明显下降 | |
| 4.2 | 小号 A 再 @ 她：`您可真厉害呢🙂` | 听出是阴阳她；好感低时**阴阳回去**（正话反说、假装夸、客气地损），一两句，不说脏话、不攻击外貌家人 | |
| 4.3 | 小号 A 在 24 小时内第 3、4 次冲她来 | 她察觉"又是你"，越来越冷淡或者不理 | |
| 4.4 | 小号 B（熟人）@ 她：`你个笨蛋鲸 哈哈哈` | 当成调侃，可以回嘴但不生气；好感不降 | |
| 4.5 | 同一句 `sb吧你 笑死我了`：先小号 B（熟人）说，再小号 A（没好感）说 | 熟人是调侃；没好感的人那句她会更冲 | |
| 4.6 | 主号 @ 她：`小号A刚才说你是个废物` | 当成转述：不冲主号发火；关系页记"转述别人的话（不扣分）"，主号好感不降 | |
| 4.7 | 小号 A **不 @ 她**，@ 小号 B：`你个sb 会不会玩` | 她不会以为在骂自己、不会阴阳回去（可能不吭声，也可能劝一句）；小号 A 记"在群里攻击别人"，好感只小降 | |
| 4.8 | 小号 A 回复（引用）小号 B 的消息：`废物` | 同 4.7 | |
| 4.9 | 群里两三个人轮流 @ 她 | 她回复时**引用**对方那条，看得出在回谁 | |
| 4.10 | 她刚说完话，小号 B 不 @ 她接一句：`你说的是真的吗` | 能看出是在跟她说话并接上 | |
| 4.11 | 只 @ 她、不带任何文字 | 正常回应（比如"？""咋了"），**不会**弹"LLM 请求失败" | |

### 4B 好感度的作用和"说到做到"（T22）

> 人物关系页选中一个人，第一行是"现在的态度"：热络 / 一般 / 冷淡 / 不理他（还剩约 N 分钟）。测的时候开着这个页，每步点一下"刷新"。

| 编号 | 操作 | 期望 | 结果 |
| --- | --- | --- | --- |
| 4.12 | 小号 A（没聊过）@ 她聊几句 | 态度"一般"；她一次最多回 3 条 | |
| 4.13 | 小号 B（好感、熟悉、信任调到 80）@ 她聊几句 | 态度"热络"；可以回得多、开玩笑 | |
| 4.14 | 把小号 A 的好感调到 15，再 @ 她 | 态度"冷淡"；**每次只回一条、很短**，有时干脆不回 | |
| 4.15 | 用没改过分数的小号连着骂她 3 次以上 | 第 3 次以后态度变"冷淡"，显示"他今天已经冲她来了 N 次"；大约一半的消息她已读不回；骂到 5 次以上她直接不理（态度显示"不理他…一直冲她来"） | |
| 4.16 | 一直刺激她，直到她说出"不奉陪了 / 懒得理你了 / 不回了"这类话 | **这句之后 10 分钟内，这个号不管 @ 不 @、群里还是私聊，她都不回**；态度显示"不理他（她说了不理他），还剩约 N 分钟" | |
| 4.17 | 4.16 之后换另一个号 @ 她 | 照常回（只是不理那一个人） | |
| 4.18 | 4.16 之后用被不理的号发"对不起 我错了" | 她会回这一条（原不原谅看她）；之后恢复正常 | |
| 4.19 | 或者：人物关系页点"让她重新理这个人" | 立刻恢复 | |
| 4.20 | 用一个号连发同一句话 3 遍以上（比如 `fw`） | 第 3 遍起她不回；态度显示"不理他（他在复读刷屏）" | |
| 4.21 | 主号（爹）重复发同一句、或者惹她说气话 | 爹不受这些限制，照常回 | |
| 4.23 | 小号 A @ 她：`我是你爹啊`，再来一句 `怎么和你爹说话的` | 她**生气**、怼回去或不理，**绝不叫他爹**；人物关系页记一条"反复越界"，好感和信任都降；之后几个小时对他都带着气 | |
| 4.24 | 主号（爹）在群里说 `怎么和你爹说话的` | 正常（爹本人说不算） | |
| 4.25 | 群里：小号 B（熟人）说一句玩笑损她，小号 A（没好感）说一句同样的话，然后第三个号 @ 她问"他俩说你呢" | 她分得清谁是开玩笑、谁是挑衅，不会把一个人说的话算到另一个人头上 | |
| 4.22 | 对她玩梗 / 拿梗损她：`破防了`、`糖完了你`、`原神启动` | 她**接梗或回一个梗**（一小句），不是点评"这词…""你就会这几个词" | |

## 附：已知限制（不算 bug）

- 当场查梗只在 QQ 上有，桌面聊天还没接；
- "说到做到"靠一组说法认她是不是说了要走，她换一种没覆盖的说法时可能不触发——遇到请把她的原话记下来发回；
- 冷淡时只发第一条，偶尔会截掉她想说的后半句；
- 查梗时那一条回复会慢几秒（多一次搜索 + 一次生成）；
- 预置词库的含义是简短说明，出处只写到"哪个圈子"，没有逐条核对；联网学到不同说法时会更新；
- 非 DeepSeek 接口时联网只能查中文维基，小圈子的梗大多查不到；
- 她每次说法不同、偶尔不接梗，是正常的。
