# AICompanion 长期架构约束

确认日期：2026-11-08。来源：项目负责人明确指定的五项长期要求。

本文件适用于 Codex、Claude Code 及后续协作者。AGENTS.md 是双方共同规则入口，CLAUDE.md 引用同一份入口。以下约束覆盖模型、人格卡、记忆、关系、表达、Agent、存储迁移和 T14—T17 的开发与审查。

## 五项约束

1. **角色身份独立于模型。** 换模型不能改变大肥鱼是谁。
2. **人格设定独立于记忆。** 换人格不能清空共同经历。
3. **关系记忆独立于聊天渠道。** 同一个人跨渠道识别时，需要经过身份关联和授权。
4. **表达能力独立于 Agent。** Agent 可以更换，但大肥鱼的表达习惯和关系状态必须保留。
5. **用户拥有角色塑造权。** 人格卡允许用户自由创作、导入、导出和切换，但不能绕过系统安全边界。

## 身份、模型与人格的边界

角色实体使用稳定的应用身份。模型提供商、模型名称、API 接口、执行框架是可替换配置，不能成为重新创建角色、重置关系或丢弃记忆的依据。用户明确编辑角色名字与设定是角色塑造操作；模型切换不能擅自执行这些操作。

同一角色的人格卡版本或激活项独立保存。切换人格描述、背景和说话风格，不等于创建另一位角色，也不能隐式更换记忆归属的角色 ID。用户明确创建另一位角色时，才按既有角色隔离机制建立独立归属。

共同经历、事实、关系、表达偏好与人格卡各有保存与删除入口。人格卡切换不清空、迁走或自动重写既有经历；删除或重置经历必须是明确的数据管理操作。用户自定义人格不能被模型默认提示、社区学习或内置卡升级悄悄覆盖。

## 人物关系与渠道的边界

人物身份、平台身份与当前会话范围分开表达。平台身份至少保留 platform、bot_account_id、platform_user_id；昵称和头像只作展示，不作自动合并依据。

跨平台或跨渠道关联必须有明确身份关联与授权记录。关联解决“是不是同一人”，授权决定“当前能使用哪些关系与记忆”。即使确认是同一人，也不自动公开其私聊事实，不把某个群的专属含义或关系细节带到另一群。

渠道适配器负责接入、权限、发送和展示；它不是关系记忆的唯一所有者。渠道变化不能擦除已经确认的人物关系，但实际读取仍必须受人物、机器人账号、群和私聊范围约束。好感度不能授予主人身份或绕过群白名单。

旧记录无法可靠关联身份或来源时保留原始数据并标记待关联 / 待确认，不按昵称、头像、当前账号或内容相似度自行贯通关系。

## 表达与 Agent 的边界

自然聊天继续使用原 ChatController 和生成链路。表达偏好、图片使用习惯、人物关系和共同经历归应用的稳定角色 / 人物身份，不归某次 Agent 会话、模型客户端或临时工具运行。

更换 Agent 或工具执行后端时，仅适配调用接口。清理 Agent 临时目录、会话缓存或运行记录不能连带清空表达习惯、关系状态与长期记忆；迁移要保留稳定标识、来源范围和恢复能力。

ExpressionService 只消费已授权的关系、社区与记忆快照，不自行授予权限。RelationshipService 维护人物关系；渠道策略决定可见范围；Agent 负责其工具执行职责。不能为可替换性另建一套平行聊天大脑或聊天数据库。

## 用户塑造权与安全边界

用户可以自由创作、编辑、导入、导出和切换人格卡，包括可编辑的人格描述、背景与表达风格。格式兼容不足应如实说明，不把暂时只支持风格导入的实现范围写成长期禁止完整人格创作的规则。

人格内容、个人记忆和系统安全 / 工具授权必须分层。导入人格卡不执行其中脚本，不更改账号绑定、群权限、工具审批、存储访问控制或实际身份关联，不将外部卡的安全覆盖字段作为可执行配置。

人格导出默认只导出用户选择的人格内容。个人经历、关系档案与社区记忆需要通过各自的授权导出流程，不因导出一张人格卡就附带泄露其他人的私聊或群资料。无法支持的卡片字段可明确提示或作为不执行的元数据保留，不能静默提升权限。

## T14—T17 的落实位置

| 阶段 | 必须落实的边界 |
| --- | --- |
| T14 表达系统 | 表达服务独立于 Agent；使用稳定角色 ID；接收已授权快照；模型与人格卡切换不重置使用习惯 |
| T15 人物关系 | 平台身份与人物关联分层；跨渠道关联需授权；关系评分与权限分开；保留作用范围 |
| T16 社区知识与记忆 | 公共知识、群专属、私人经历分层；知识学习不覆盖人格或越权串联人物 |
| T17 综合整合 | 原大脑统一消费快照；验证替换模型 / Agent、切换人格与渠道后的状态连续性和权限边界 |

## 实施与审查检查项

- 替换模型或 Agent 后，角色身份、已确认关系、表达偏好和共同经历均保留。
- 切换人格卡后，历史与记忆不被清空；用户自定义内容没有被内置默认值覆盖。
- 相同昵称、头像或相似说法不会自动合并人物；明确关联后仍核验当前会话可见范围。
- 高好感度、自定义人格与外部知识不能提升工具权限、成为主人或突破群授权。
- 人格卡导入 / 导出 / 切换确实走用户可控入口，错误或取消不破坏旧内容。
- 数据迁移有备份或可验证恢复方案，不擅自覆盖已有目标或删除旧数据。

本文件记录长期要求，不代表这些功能现已全部实现。当前完成情况以 [实施记录](implementation_status.md) 和各阶段验收为准。更改共同规则仍按 AGENTS.md 的 PR 流程，项目负责人决定最终合入与发布。
