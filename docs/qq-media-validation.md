# QQ 识图和表情包验收

## 准备

更新代码后，从托盘彻底退出桌宠，再运行 `main.py`。自动管理模式会同步安装 v0.4 插件并重启组件；接入外部 AstrBot 时，需要在其管理页重载桌宠插件。

在“设置 → 聊天平台”确认“已连接”，填写自己的 QQ 号、勾选允许的群；打开“看懂收到的图片”和“聊天时可以发表情包”，点保存。识图要求当前角色使用 DeepSeek 官方 API；高级设置的识图模型默认 `deepseek-flash`。不需要另填一套密钥，原聊天模型保持原设置。

默认表情是仓库自带的原创鲸娘。使用其他图库时，在“表情图库”选择包含 `manifest.json` 和 `memes/` 的社区基础包，或按分类放图的普通目录：

```text
我的图库/
  happy/开心.png
  sleepy/晚安.gif
```

使用自己有权发送的素材。支持 PNG / JPEG / GIF / WebP；一次最多发送一张，默认同一会话间隔至少 60 秒（高级设置可调）。清空目录输入框并保存即可恢复自带图库。

## 功能检查

1. **纯图片**：用自己的 QQ 私聊机器人，只发一张内容清晰的图片，检查回复是否与图片有关。
2. **图文**：发送截图并问“这张图写了什么？”，检查数字 / 文字能否准确识别。一次最多 3 张；图片会压缩到最长边 1600，动图识别首帧。
3. **表情**：说“好开心，配一张开心表情”，检查收到图片或文字配图片。再说“只发一张开心表情”，间隔超过冷却后检查纯表情回复。
4. **允许的群**：勾选测试群并保存，在群里 @ 机器人并附图片。确认识图正常，且不提桌面私聊的原始记录、摘要或已标为 private 的记忆。
5. **权限**：未勾选的群或未授权的陌生人不应触发识图 / 回复。默认不回复陌生人私聊。
6. **关闭识图**：关掉识图并保存，等一次插件心跳（最多 15 秒）再发图，应说明图片尚未识别，不能编造看到了什么。关掉表情开关后只发文字。
7. **错误恢复**：在不改 API 密钥的情况下断网后发图，检查提示不能识图且不泄露接口或图片传输数据；恢复网络后重试。

群里没有叫她的图片不自动识图，避免刷屏时反复上传和产生费用。QQ、桌面共享的是原桌宠的人格与记忆；原图只用于当前请求，历史保存视觉描述。
