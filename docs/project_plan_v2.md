## 1. 版本目标

v1 完成了"可对话、可通话、有记忆的 Live2D 陪伴角色"。v2 把产品形态从"打开应用 → 看到角色"改为：

1. **桌宠为主体**：开机或启动后，角色直接出现在桌面最顶层，聊天面板只在需要时从角色身上唤出。
2. **一个模型一个角色**：每个大模型配一个二创萌化角色，换模型就换角色。
3. **能干活的 agent**：角色可以调用工具完成任务，干活的过程会通过姿势、气泡和台词表现出来。
4. **活人感**：状态表演、交互小反应、按情境主动说话、作息与好感度，都基于真实事件，不随机刷存在感。

第一版只完整交付 **DeepSeek 鲸娘**，另外两个角色先交付角色包框架和人设草案。

## 4. 参考实现分析

调研了 DeepSeek Harness（DSH）生态里三个鲸鱼桌宠。它们都是 DSH 插件，不直接调用模型，而是读取 agent 的运行状态再表现出来。

| 项目 | 值得借鉴的做法 | v2 的取舍 |
| --- | --- | --- |
| pet-whale | 7 种状态（idle / think / working / celebrate / error / disappointed / wait）并带优先级；思考时滚动显示推理文字；戳、双击、拖拽、摇晃、撞屏幕边缘各有反应；三档好感度；完成提醒、休息提醒 | 采用状态集合和优先级思路；推理文字改为**摘要短句**，避免刷屏 |
| dsh-whale-pixel-pet | 用纯函数把 agent 事件折叠成状态快照（任务 / 进度 / 用量），遇到不认识的事件直接忽略；按工具类型换姿势；除角色本体外鼠标穿透；闲置时走动、犯困；Electron 透明置顶窗口；底部三行状态栏 | 采用 reducer 设计和鼠标穿透；状态栏做成可选；走动先做"小范围挪动"，不满屏乱跑 |
| dsh-whale-musume | 47 张姿势加过渡，避免切换时闪黑或重叠；每 5–8 分钟结合当前任务主动说话；深夜安静；按时段问候 | 采用"多姿势立绘 + 过渡"路线；主动说话接到现有主动互动冷却上 |

**差异**：参考项目只"表演"别人的 agent，而 AICompanion 自己就是 agent，同时还有对话、记忆、语音和情绪。所以状态来源是本应用的事件总线，不用读外部状态文件。

## 5. 总体架构

```text
app.py
 └─ AppShell（新）—— 持有 Database、ChatController、SpeechOutput、托盘、单实例锁
     ├─ PetWindow（重构自 desktop_pet.py）—— 常驻主体，持有 AvatarView
     │    ├─ 角色画布（贴片动画引擎）
     │    ├─ 气泡层（台词 / 推理摘要 / 确认请求）
     │    └─ 可选状态行（任务 · 进度 · 用量）
     ├─ ChatPanel（由 MainWindow 拆出）—— 按需打开的聊天、历史、设置入口
     ├─ CharacterRegistry（新）—— 加载角色包，切换角色＝切换模型＋人设＋素材＋音色
     ├─ AgentRunner（新，后台 QThread）—— 工具调用循环
     │    └─ ToolRegistry（新）—— 工具定义、风险分级、审批、审计
     ├─ PetStateReducer（新，纯函数）—— 事件 → 状态快照
     └─ BehaviorEngine（新）—— 作息、闲置、交互反应、主动说话、好感度
```

**事件总线**：聊天、语音、agent、交互、时间这些来源都发出统一的 `PetEvent(kind, payload, ts)`。`PetStateReducer` 把事件折叠成 `PetSnapshot`，`PetWindow` 只负责渲染快照。reducer 是纯函数，可以直接写单元测试，不需要启动 Qt。

### 6.3 鲸娘素材规格

参考图是带背景和文字的梗图。桌宠需要的是同一造型的**单独角色立绘**：

| 项 | 要求 |
| --- | --- |
| 格式 | PNG，透明背景，无文字、无桌面道具（电脑、书堆可以作为 `working` 姿势的一部分单独出现） |
| 画布 | 美术素材 1254×1254（以素材包 manifest.json 为准），角色底部中心对齐同一锚点；运行时统一裁切缩放为 477×640 |
| 一致性 | 用同一张定稿图作参考批量生成，发色、耳鳍、头饰、围裙鲸鱼图案保持一致 |
| 首批姿势（10） | idle、talk、think、working、celebrate、error、wait（拿沙漏或举"？"牌）、sleepy、grabbed（被拎起）、poked |
| 贴片 | 每个姿势一张闭眼版 + 一张张嘴版（只需眼睛、嘴巴区域正确），沿用 Emilia 的贴片机制 |
| 可选 | 3–5 张"干活中"变体（翻文件、敲键盘、查资料），按工具类型切换 |

素材由用户用自己的生图工具出图。工程侧提供 `tools/check_sprites.py`，校验尺寸、透明度、锚点和贴片坐标，并生成预览拼图。

## 7. 桌面常驻与界面

### 7.1 启动与常驻

| 功能 | 做法 |
| --- | --- |
| 启动即出现 | `AppShell` 启动后直接显示 `PetWindow`；`ChatPanel` 延迟到第一次打开时才创建 |
| 最顶层 | `WindowStaysOnTopHint` + `Tool` 窗口（不占任务栏）；每 2 秒检查一次，被压下去就调用 Win32 `SetWindowPos(HWND_TOPMOST)` 恢复 |
| 全屏避让 | 检测到前台是全屏应用（游戏、视频、演示）时自动隐藏，退出全屏后恢复；可以关闭 |
| 开机自启 | 设置里的开关，写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`；只对打包后的 exe 生效 |
| 单实例 | `QLocalServer` 锁；重复启动时唤起已有角色，而不是再开一个 |
| 鼠标穿透 | 根据当前姿势 PNG 的 alpha 生成 `QRegion` 并调用 `setMask`，只有角色本体响应鼠标；切换姿势时同步更新 |
| 多屏与 DPI | 沿用 `pet_geometry.py` 的保存和修正逻辑，补充 DPI 缩放下的测试 |
| 关闭 | 右键菜单的"让她休息"是隐藏到托盘；"退出"才真正释放麦克风和线程，沿用现有退出流程 |

### 7.2 桌宠上的界面

| 元素 | 说明 |
| --- | --- |
| 气泡 | 角色头顶的圆角气泡，显示台词、推理摘要、确认请求；8 秒或下一条消息到来时淡出；可在设置里关闭 |
| 确认气泡 | 带"可以 / 不行 / 看详情"三个按钮，用角色口吻说明要做什么 |
| 状态行（可选） | 角色脚下一行小字：`整理下载文件夹 · 3/7 · 1.2k 词元`；默认关闭 |
| 快捷输入 | 双击角色弹出单行输入框，回车发送，不必打开完整聊天面板 |
| 右键菜单 | 打开聊天面板、开始/结束通话、打断、切换角色、大小、置顶开关、勿扰模式、退出 |
| 托盘 | 保留，作为角色被隐藏时的入口 |

### 7.3 聊天面板

由 `MainWindow` 拆出，去掉其中的角色画布，只保留历史消息、输入框、设置入口、记忆管理和 agent 操作日志。打开时贴在角色旁边，关闭时只是隐藏，不影响桌宠。

## 8. 状态机

| 状态 | 触发 | 表现 | 优先级 |
| --- | --- | --- | --- |
| error | 模型或工具失败 | error 姿势 + 抖动，气泡说明原因；点击复制错误；下一次成功后清除 | 1（最高） |
| wait | 等待用户确认危险操作 | wait 姿势 + 确认气泡 | 2 |
| grabbed | 正在被拖拽 | grabbed 姿势 | 3 |
| celebrate | agent 任务完成 | celebrate 姿势，1.5 秒后回落 | 4 |
| talk | 正在播放语音或输出回复 | talk 姿势 + 口型贴片 | 5 |
| working | 正在执行工具 | 按工具类型选择 working 变体 | 6 |
| think | 已发请求、尚未开始输出 | think 姿势 + 推理摘要气泡 | 7 |
| poked | 被戳 | poked 姿势 0.8 秒 | 8 |
| sleepy | 闲置超过 20 分钟或深夜 | sleepy 姿势，降低眨眼频率 | 9 |
| idle | 其他情况 | idle 姿势 + 呼吸、眨眼 | 10 |

规则：
- 每个状态至少停留 600 毫秒，防止闪烁。
- 姿势切换使用 150 毫秒淡入淡出。
- `PetStateReducer` 对未知事件保持原状态，不抛出异常。
- 情绪（开心、害羞、失落、生气）作为叠加层，影响 idle/talk 时的表情贴片和台词选择，不新增独立状态。

## 9. Agent 能力

### 9.1 工具调用

- `openai_compatible_client.py` 增加 `tools` 参数，流式解析 `tool_calls` 增量，同时保留 `reasoning_content`（用于推理摘要）。
- 不支持工具调用的模型（在 `character.json` 中标记）自动降级为纯聊天，并在界面上说明。
- 新增 `AgentRunner`，运行在后台 QThread：发送请求 → 执行工具 → 回填结果 → 继续，直到模型给出最终回复。
- 限制：单次任务最多 12 步，单个工具 30 秒超时，总时长 5 分钟。
- 复用现有 `cancellation`：用户打断或说"停"时立即取消，并丢弃迟到的结果。
- 角色在 agent 运行期间仍然可以聊天。聊天走原有对话通道，agent 结果完成后再插入对话。

### 9.2 工具与风险分级

| 级别 | 工具（v2 首批） | 审批 |
| --- | --- | --- |
| 只读 | 读取白名单目录文件、列目录、网页搜索/读取、读取剪贴板、查询提醒、当前时间/天气、屏幕截图（需用户每次手动开启） | 无需确认，但写入日志 |
| 可撤销 | 写入白名单目录（新建或覆盖前先备份）、写剪贴板、新建/修改提醒、打开网址或应用 | 首次使用某类工具时确认，可以选择"本次会话不再询问" |
| 危险 | 删除或移动文件、运行命令或脚本、发送消息或邮件、白名单以外的任何路径 | **每次都要确认**，确认气泡显示完整参数；v2 首批只开放"移动到回收区"，不直接删除 |

- 白名单目录在设置中配置，默认为空，不能把整个盘符设为白名单。
- 后续接入 MCP（Python `mcp` 客户端），外部工具一律归为"危险"级别，除非用户手动降级。

## 10. 活人感行为层

| 行为 | 设计 | 约束 |
| --- | --- | --- |
| 干活时有反应 | 开始时说一句（"交给我！"），超过 30 秒报一次进度，完成时庆祝并一句话总结结果，失败时沮丧并说明原因 | 台词来自 `lines.json`，总结来自模型；同一句 10 分钟内不重复 |
| 推理摘要 | 思考时显示一句推理摘要（截取 reasoning 并压缩成一句话，最多 30 字） | 不显示完整思维链 |
| 交互反应 | 戳、连戳、摸头（在头部区域来回移动）、拖拽、摇晃、扔到屏幕边缘，各有不同姿势和台词 | 连续骚扰会触发"轻微生气"，并接入现有情绪规则 |
| 作息 | 按时段问候；23:00–7:00 降低主动说话频率；长时间闲置时犯困、打瞌睡；用户回来时醒来打招呼 | 沿用"重启不重复问候"的持久化去重 |
| 主动说话 | 依据真实事件：用户离开很久后回来、长时间连续工作提醒休息、agent 后台任务完成、提醒到期 | 沿用一小时冷却；全屏和勿扰模式下静音；设置里有"打扰度"三档 |
| 好感度 | 接入现有关系状态和每日信任上限：三档影响问候、被戳时的反应和称呼 | 不新增数值界面，不用好感度诱导用户 |
| 用量吐槽 | agent 任务的词元用量超过阈值时，鲸娘会说"词元在自己消耗！"之类的台词 | 用量数字来自本地统计，不代表账单 |
| 小范围移动 | 闲置时偶尔在当前位置附近挪几步，鼠标靠近时转向 | 可关闭；永不挡住用户正在操作的窗口中心 |

## 13. 验收用例

1. 冷启动：在不打开聊天面板的情况下，2 秒内出现角色；任务栏没有多余窗口。
2. 重复启动 exe：已有角色闪一下回应，不会出现第二个角色。
3. 打开一个置顶窗口压住角色，2 秒内角色回到最上层；播放全屏视频时角色隐藏，退出全屏后恢复。
4. 点击角色身边的透明区域，能点中下面桌面上的图标。
5. 发一句话：think（有推理摘要）→ talk（有口型）→ idle，每个状态至少显示 600 毫秒。
6. Agent 任务"把下载目录里的 PDF 移到 D:\资料"：显示 working 姿势；移动前出现确认气泡；拒绝后不执行；同意后完成并庆祝；日志里有完整步骤；"撤销"能把文件还原。
7. 白名单以外的路径一律拒绝，即使模型坚持要求也一样。
8. agent 运行时说"停"：1 秒内停止，迟到的工具结果不写入对话和日志。
9. 连戳角色 8 次：出现轻微生气反应，过一段时间后恢复。
10. 23:30 闲置：角色进入困倦状态，不会主动开口；早上第一次活动时问候，且只问候一次。
11. 从鲸娘切换到艾米莉娅：模型、音色、素材、记忆全部切换，两个角色的数据不互相读取。
12. 开机自启开关打开后重启电脑，角色自动出现；关掉开关后不再自启。

## 14. 风险与决策

| 风险 | 处理 |
| --- | --- |
| Q 版素材风格不一致、姿势切换跳位 | 统一画布和锚点；用 `check_sprites.py` 自动校验；先出 3 张定风格，再批量生成 |
| Qt WebEngine 常驻内存和 CPU 偏高 | P2 结束时测量空闲时的 CPU 和内存；如果空闲 CPU 超过 3% 或内存超过 300 MB，改用纯 QPainter 绘制贴片动画（不需要 WebGL） |
| Windows 置顶不稳定 | 置顶守护 + 全屏避让；记录哪些应用会抢置顶 |
| Agent 误操作文件 | 白名单、三级审批、备份、撤销，首批不开放直接删除 |
| 模型工具调用格式不稳定 | 解析失败时重试一次，再失败则降级为纯回复并记录；用 mock 流写测试 |
| 主动行为让人烦 | 冷却、勿扰、打扰度三档；以实际使用一周的反馈来调整 |
| 二创形象 | 自用和博客展示；应用图标和宣传主图不直接使用各公司官方 logo |
| DeepSeek 模型名或接口变化 | 模型名通过配置读取，不写死在代码里；保留诊断工具 |
